# 番茄小说写作

本技能不给通用写作建议，只写有出处的规则，出处分两类：

- **第一到第七节**来自本项目自采的 360 本番茄榜单数据（`.scrape/fq_books.json`），讲的是这个平台上什么有用。
- **第七节末尾五条与第八节「人味」**来自本仓 `04-审校/` 对已写章节的分段实测，讲的是这本书自己反复犯的错。榜单数据量不了这一层，所以单列并标明来源。

**读者画像**：通勤和睡前用手机碎片时间刷，算法推送而来，随时可以划走。**为普通读者写，不为文学读者写。**

## 一、硬性规范（做到即可，做过头不加分）

| 项 | 值 | 依据 |
| --- | --- | --- |
| 每章字数 | **2200 字左右** | 360 本中位数 2190。**本仓的容差与 10 章均值只在 `03-正文/README.md` 第四节有一份，以那一页为准** |
| 每天更新 | **2 章 / 约 4900 字** | 中位数 2.24 章/天 |
| 书名长度 | 13–14 字 | 高分组与低分组中位数分别为 14 和 13 |
| 每章事件数 | 1 件 | — |

**这四项都不是胜负手，别在上面加码。** 控制章数后（60–120 章，121 本），成绩高于中位的书更新 2.29 章/天，低于中位的 2.26 章/天，几乎一样。书名用逗号分段（中位 1104）、冒号分段（1072）、不分段（985）差距同样在噪声范围内。

写得快只能让你不掉队，不能让你赢。省下的精力放在下面第二节。

## 二、真正拉开差距的两件事

### 1. 钩子必须在第 1 章兑现

书名承诺了什么机制，第 1 章就要出现。**一组干净的同区间对照：**

| 书 | 体量 | 机制兑现 | 阅读/章 |
| --- | --- | --- | --- |
| 开局模拟被打爆，金丹爆星什么鬼 | 19.2 万字 / 92 章 | 第 1 章 | **1670** |
| 天降玄碑：我建立不朽仙族！ | 21.5 万字 / 103 章 | 第 7 章 | **341** |

两本体量相当、同批新书，唯一显著变量就是钩子位置。

**担心第 1 章就给会导致后面没爽点？解法不是往后拖，是让第一次使用失败。** 机制当场亮明（读者知道这本书怎么玩），但没有过早上强度，还天然生成了下一章的钩子。

### 2. 章节标题写事件，不写气氛

高位标题都在讲一件事，低位标题都在描述一种状态。

| 好 | 差 |
| --- | --- |
| 退师！必须退师！ | 一切的开始 |
| 不要选截教 | 神明的傲慢，俯瞰众生 |
| 登基称帝，人生模拟系统绑定 | 辞官买地，避世藏拙 |
| 又死了 这回死得更快 | 玄策绯眉 |

**判定方法**：读完标题，能不能说出"这章会发生什么"？说不出就是气氛词，重写。

**判定要落在书面上**——哪几章过、哪几章没过、备选是什么，写进细纲裁决记录。口头「全部过」不算：本仓有过一次「逐条过了，36 个全部过」的记录，实际没做，而同时期两个说不出事件的章名一直挂着没改。

注意「大白话」不是标准本身——「窃蛋的古蛇」「元婴末路」都不白话，照样排在前面。**大白话只是写事件最省力、最不容易写砸的手段**，所以默认用它。

## 三、行文风格

1. **不用生僻词，不堆四字成语。**「长生久视」写成「不会死」。
2. **短句为主。** 一句话说完一件事，别套从句。
3. **对话多于描写。** 大段景物描写是完读率杀手。
4. **别解释设定。** 让读者从主角怎么用金手指看懂它的规则，不要旁白说明。
5. **章末必须留钩子。** 最后一句话要让人想点下一章。
6. **凄惨期要带喜剧感。** 纯写受苦读者会累；同样的苦，加一层自嘲或荒诞就追得动。
7. **连写多章要查自己的口头禅。**「忽然」「这才＋明白」「在心里过了一遍」「很久」这类旁白引子，各章留一处；让读者自己撞上结论，比告诉他「云昭明白了」更好。（本条来自本仓 `04-审校/` 三轮实测：同一批引子分别出现 17 处 8 章、9 处 5 章、20 处 10 章，其中一章一个词用了 5 次。）

## 四、简介格式

标签串开头，然后短句递进，最后用主角一句口语化的狠话收尾。

```
【模拟+修仙+苟道+无女主+爽文】

云昭是青玄宗的杂役，扫了三年地，剑都没摸过。

后来他发现自己能模拟。模拟里死一次，身上是真疼。

第一次他冲进后山，死了。第二次他绕着走，还是死了。第三千次，他终于摸清那扇门后面有什么。

现在他不用试了。他出手，就没输过。

别人问他怎么每次都赢。他说：我死过三千次了，你才死一次，你打得过我？
```

**⚠ 上面这段只示范格式，情节不作准。** 它写于 2026-08-27，早于几条机制终裁，三处与已封存设定相撞：门十步内模拟起不来（不会给死亡画面，只会黑）；「三千」是全书累计死亡数，不是对那扇门试的次数；门后是后期有人走进去看见的，不是模拟摸清的。**照抄这三句会写出一份与设定打架的简介。** 要一段相容的，可用这个形状：

```
有人给他递了张纸条。模拟里他赢了三场。现实里第三场，他被打到吐血。
```

**避免**：破折号、排比、对仗。那是宣传文案的腔调，不是番茄简介的腔调。

## 五、标签选择

样本内标签频次（360 本）：

| 标签 | 本数 | 占比 |
| --- | --- | --- |
| 穿越 | 205 | 57% |
| 都市 | 105 | 29% |
| 系统 | 88 | 24% |
| 玄幻 | 71 | 20% |
| 开局 | 59 | 16% |
| 单女主 | 25 | 7% |
| 无女主 | 14 | 4% |

- **`穿越` 是这个池子的默认设置**，不是特色。可以用，但正文里一句话带过——不要写穿越震撼，读者早免疫了。它的真正价值是给主角的谨慎一个来源。
- **`无女主` 是少数派**（玄幻/仙侠 77 本里只有 5 本）。选它要靠"省章节预算"这个理由，不能说它是趋势。
- 玄幻脑洞类的模拟流有现成读者，且对新机制宽容。

## 六、评估一本书时的方法论

**阅读/章 = 总阅读 ÷ 总章数，严重受书龄混淆。** 本样本里高分组书龄中位 53 天 / 114 章，低分组 354 天 / 691 章——所谓"高分"很大程度只是"新"。

| 规则 | 说明 |
| --- | --- |
| 只在字数或章数相近的书之间比阅读/章 | 跨区间比会得出相反结论 |
| 跨区间要比总阅读 | 《开局长生万古》阅读/章仅 425，但总阅读 115 万是样本内修仙轴第一 |

**基准线（15–25 万字，108 本）**：25% = 662，中位数 = 1104，75% = 1925，90% = 3144。**（2026-08-26 快照；样本越老分位越下沉，拿它判上线后的新书会偏严——上第 36 章推荐评估前重抓一次。）**

重新计算或换区间时运行：

```bash
node .cursor/skills/fanqie-webnovel-writing/scripts/bench.mjs 150000 250000
```

## 七、动笔前的检查清单

- [ ] 书名承诺的机制，第 1 章出现了吗
- [ ] 第一次使用是失败的吗（避免过早上强度）
- [ ] 每个章节标题都能说出"这章发生什么"吗
- [ ] 这一章只讲了一件事吗
- [ ] 章末最后一句能勾住人吗
- [ ] 有没有旁白在解释设定
- [ ] 有没有生僻词和成语堆砌
- [ ] 字数在 `03-正文/README.md` 第四节的容差内、没拉低 10 章均值吗

下面五条来自本仓 `04-审校/` 的实测，不来自榜单数据。上面八条覆盖的是标题、钩子、字数、禁用词——那几类在最近几轮里全是零命中，说明它们在起作用；而同期七十余条必改**一条都没被上面八条拦住**，全落在下面这五类里。

- [ ] 本章每一个相对时间词（昨天／上个月／半个月／三年前／去年冬天）都换成了事件指代，或对过 `02-大纲/10-逐章日账.md` 了吗
- [ ] 本章提到的前文的事——谁说过什么、伤在哪、谁在场、东西在谁手里——回开源章核过原句了吗；第一段接住上一章末句的时辰／地点／在场／物件四项了吗
- [ ] 本章让读者数的每一个数（几个字、几个人、几回、第几行、几根指头、几个时辰）作者自己先数过一遍了吗
- [ ] **旁白替读者算的每一笔账，回场景里核过了吗**——场景往往是对的，错的是旁白加的那个总结数，而这本书的爽点全靠「算得准」立着
- [ ] 模拟时长、死亡配额、伤痕退没退、扫洒范围这类已封存口径，过了 `03-正文/README.md` 自检第 4–6 条和 `01-设定/02-模拟器机制.md` 第五节了吗

## 八、人味

**本节来源：本仓 `04-审校/` 四条通道对 0001–0052 的分段互验，不来自榜单数据**——`fq_books.json` 里没有任何字段能量「人味」。列在这里是因为它是本书目前唯一被量化验证过的质量变量。

### 1. 每一章都要有一件正在他身上发生的事

这是本节唯一经过证伪检验的一条。把身体感受分成两族：

- **神识族**——白、顶、发虚、撑铺板。**那是模拟这件工具的收据。**
- **处境族**——饿、疼、冷、手抖、腿软、皮磨破、袜子粘着脚底。**那是处境的收据。**

**读者感觉得到的是后者。** 实测三段 × 两类章（A＝他在挨／在输，B＝他在算／在赢）的处境族密度：

| 段 | A 类 | B 类 |
| --- | --- | --- |
| 0001–0018 | 2.25 | 0.35 |
| 0019–0036 | 2.0 | 0.60 |
| 0037–0052 | **0.8** | 0.36 |

**B 类一路都低——处境族从来没在「赢」的章里有过。** 而 A 类前两段稳、第三段塌，人味厚率随之从 94% 掉到 63%。

最干净的一组对照是同一天同一口井：一章是在模拟里试，处境族 0；另一章是在现实里干，处境族 4。**差别不在写得用不用心，在他有没有真的用身体干那件事。**

**所以规矩不是「多写身体描写」，是让这一章有一件正在他身上发生的事。它不必是打斗**：一盆凉水、一只粘着脚底撕下一层皮的袜子、肩上一道压出来的沟都算。范例的共同点是**全都是干活干出来的，一个形容词都没有**——「手心的皮全磨掉了，两只手都在渗血，抓着绳子黏在一起，一松开又扯开」。

### 2. 配角开口要认得出是谁

每个反复出场的配角给一句口头禅或一个只属于他的句式。**检验：把这句话换成别人说，还成立就是没写出人。**

**而「有自己的算盘」这件事，主语必须是配角自己。** 这本书的叙事习惯是让主角把每个人的账拆给读者看——如果允许「主角替他算出来的算盘」也算数，那么每个配角看上去都有算盘，这条就作废了。对照组：一章里配角只念公文、只说功能句，主角在旁白里把他的动机算得清清楚楚，那一章仍然是薄的；另一章同一个配角自己有嗓子、有得意、有想要的东西，那一章就厚。

### 3. 对话像人说话

不复述前文、不解释设定、允许答非所问、允许说半句；两个人对话不要像两段旁白轮流念。**模拟里的对话不算数**——读者知道那是主角自己编出来的人。

### 4. 不替读者想通

「他明白了」「他忽然想起」「他想了很久」各章最多一处。把结论留给读者自己撞上。

### 5. 别让他一路全对

主角需要「想岔了／赌错了／犹豫了」的时刻。全对全稳会让人物变纸片——而这恰恰最容易发生在他开始赢的那些章里。
