# 《杂役模拟三千世，一出手就无敌》前 13 步设定清单

## 一页速查

不想读全文就看这一页。

**这本书是什么**：青玄宗最底层的杂役，发现自己能模拟人生。模拟里死一次，身上真疼一次。他死了三千次，换来现实里出手就赢。

**怎么写**

| 项 | 定死的值 |
| --- | --- |
| 每章字数 | 2200 字左右 |
| 每天更新 | 2 章上下（约 4500–5000 字） |
| 每章讲几件事 | 一件 |
| 章末 | 必须留一个让人想点下一章的钩子 |
| 用词 | 大白话。不用生僻词，不堆成语，短句为主，对话多于描写 |
| 章节标题 | 写发生了什么事，别写气氛。「又死了 这回死得更快」对，「避世藏拙」错 |

**三条不能违反的**

1. **第 1 章就要出现模拟**，而且第一次要失败。拖到第 7 章才给钩子的那本书，成绩只有同行的五分之一。
2. **别解释设定**。模拟器怎么运作不用说明，让读者从他怎么用看懂。
3. **凄惨要带笑**。「死法一次比一次蠢」这条线自带喜剧感，纯写受苦读者会累。

**前 5 章怎么排**：第 1 章挨欺负，昏过去时发现能模拟，但只撑了三息；第 2 章再模拟，被打死，醒来脸真疼；第 3 章连死七八次，死法一次比一次蠢；第 4 章发现规律——模拟只能推演他已经知道的事；第 5 章第一次活过一整天，拿到一条信息，在现实里赢下第一场。

**下面全是给这些结论撑腰的数据和细节，写的时候不用每次都看。**

## 1 故事种子

```
青玄宗最底层的杂役发现自己能模拟人生。模拟里死一次，痛觉就真一次。他在模拟里死了三千次，换来现实中每次出手都不会输。
```

## 2 卖点提炼

```
主卖点：确定性，不是变强。读者在他出手前就知道他会赢，爽点落在「怎么赢」和「对手什么时候发现自己早输了」。

副卖点：痛觉让「苟」有了重量。他不是怂，是真疼过。这一条把「苟」从没性格里救回来。

差异点：番茄 360 本榜单样本里，模拟 × 苟 × 修仙三者同时命中的是 0 本。两两组合都有活体，三样焊在一起没人做。
```

## 3 题材定位

```
平台：番茄
分类：玄幻脑洞（不是东方仙侠）
标签串：模拟 + 修仙 + 苟道 + 无女主 + 爽文
```

> **这一串必须和第 7 格简介开头的标签串完全一致**（2026-08-27 已统一，以第 7 格为准）。原来这里写的是「模拟 + 修仙 + 苟道 + 杀伐果断 + 无女主 + 系统」，和第 7 格对不上。
>
> **展示串和后台勾选是两回事**：下面「标签串的实测校准」讲的是番茄后台实际能勾什么（`系统` `穿越` `开局` 已验证有效），那是填表用的，不进展示串。
>
> **另外**：`系统` 只能当平台标签。**正文里这两个字一次都不许出现**，见 `01-设定/05-术语与命名表.md` 第 6.3 节。

**依据**：《一年抽取一词条，模拟的也可以？》《系统赋我长生》《谁把我仙侠游戏退出键扣了？》全部挂在玄幻脑洞。模拟流在这个分类里有现成读者，而且脑洞类对新机制更宽容。

**实测补强**（`.scrape/fq_books.json`，番茄 360 本样本）：玄幻脑洞在样本里共 20 本，阅读/章从 4812 到 287，跨度极大——说明这个分类**不保底，但天花板高**。头部四本（4812 / 3500 / 3407 / 3144）全部是 16–25 万字的新书，证明脑洞类新书能在短期内冲起来，不需要靠长度熬。

三本模拟流的实测值：

| 书名 | 字数 | 章数 | 阅读/章 |
| --- | --- | --- | --- |
| 开局模拟被打爆，金丹爆星什么鬼 | 19.2 万 | 92 | 1670 |
| 瘟疫模拟：开局投放 Necroa | 22.3 万 | 76 | 945 |
| 一年抽取一词条，模拟的也可以？ | 122.9 万 | 577 | 889 |

**标签串的实测校准**：模拟流两本头部书的实际标签是「玄幻/系统/穿越/架空/开局」和「玄幻/系统/穿越/架空/东方玄幻」——都带**穿越**和**系统**，都不带「修仙」「苟道」。番茄的标签是平台词表，`模拟`、`苟道` 未必是可选项，填的时候以平台实际下拉为准，优先勾中 `系统` `穿越` `开局` 这三个已验证有效的。

## 4 目标阶梯

按番茄机制倒推，不是拍脑袋。

| 节点 | 目标 |
| --- | --- |
| 8 万字 / **第 36 章** | 触发第一次推荐评估，追读率必须 ≥12%（每章 2200 字，30 章只有 6.6 万字，够不着） |
| 15 万字 | 未进验证期则平台自动发起评估，3 次用完出局 |
| 首秀 | 在读约 3 万，随后数周维持 1–3 万 |
| 15–25 万字 | **阅读/章 站上 1104**（同区间 108 本的中位数），否则这本书在同龄书里已经落后一半 |
| 100 万字 | 进入模拟流对照区间（那三本是 19.2 / 22.3 / 122.9 万字） |

**日更**：每章 2200 字左右，每天 2 章，约 4500–5000 字。

> ⚠️ **原来写的「6000–9000 字/天硬门槛」不成立。** 360 本实测：每章字数中位数 2190，更新速度中位数 2.24 章/天，折合约 **4900 字/天**。
>
> 更要紧的是，**更新速度根本不是胜负手**。控制章数后（只看 60–120 章的书，121 本），成绩高于中位的 61 本更新 2.29 章/天，低于中位的 60 本更新 2.26 章/天——**几乎完全一样**。写得快不会让你赢，只会让你不掉队。
>
> 所以别把力气花在拼更新量上。4900 字/天 是入场券，达到就行，剩下的精力放在钩子上。

**阅读/章 的及格线怎么来的**：见附录 E。同字数区间比才有意义，跨区间比是错的。

## 5 主角剧情匹配

性格与引擎必须咬合，否则人物是飘的。

```
性格：算准了才出手（主动的苟，不是怕事）
引擎：模拟器提供确定性
冲突来源：模拟只能推演他已知的信息——信息不全时，他必须赌
人物弧光：从「只打有把握的仗」→ 第一次在没把握时出手
```

## 6 开篇策略

```
第 1 章交付三样：杂役身份、首次模拟、模拟失败。
章末钩子：他发现还能再模拟一次。
第 2–4 章：模拟一直不出货，死法一次比一次蠢。
第 5 章：用模拟换来的信息，在现实里赢下第一场——很小的一场。
第一次大爆发：第 15–16 章（月考第一）。
```

**依据**：一组干净的同区间对照。两本书字数章数几乎一样，差别只在书名承诺的机制什么时候兑现：

| 书 | 字数 / 章数 | 第 1 章标题 | 机制兑现于 | 阅读/章 |
| --- | --- | --- | --- | --- |
| 开局模拟被打爆，金丹爆星什么鬼 | 19.2 万 / 92 章 | 登基称帝，人生模拟系统绑定 | **第 1 章** | **1670** |
| 天降玄碑：我建立不朽仙族！ | 21.5 万 / 103 章 | 辞官买地，避世藏拙！ | 第 7 章 | **341** |

同区间 108 本的中位数是 1104。前者站在约 66 分位，后者跌到 25 分位以下（25 分位 = 662）。**这两本体量相当、都在同一批新书里，唯一显著变量就是钩子位置**，所以这个对照比笼统的「五分之一」更站得住。

>
> 裁决理由：机制兑现的位置没有变——第 1 章照样亮明模拟，钩子该在哪还在哪。往后挪的只是**第一次见效**，换来的是前四章「攥着彩票一直不中奖」的等待感。读者不是在看倒霉蛋受苦，是在看一个手里有牌却打不出去的人受苦，前者只有同情，后者每一章都在等。

## 7 书名与简介

**书名**

```
杂役模拟三千世，一出手就无敌
```

**简介**（大白话版，推荐用这版）

```
【模拟+修仙+苟道+无女主+爽文】

云昭是青玄宗的杂役，扫了三年地，剑都没摸过。

后来他发现自己能模拟。模拟里死一次，身上是真疼。

第一次他冲进后山，死了。第二次他绕着走，还是死了。第三千次，他终于摸清那扇门后面有什么。

```

## 8 势力体系

```
开篇只出现一个宗门加一个对手，其余全部后置。

青玄宗内部三层：杂役院 / 外门 / 内门。

宗门之上有仙盟，宗门之外有魔门——这两样第 30 章之后再提。

## 9 力量体系

```
炼气 → 筑基 → 金丹 → 元婴 → 化神
五层，到此为止。
```

不要自创境界名。番茄不奖励设定密度，奖励钩子密度；读者零学习成本才能追读。

## 10 地图推进

```
杂役院 → 外门 → 内门 → 山下的城 → 宗门之外
```

每一段对应模拟能覆盖的范围。模拟范围随修为扩大，地图跟着开。

## 11 伏笔设计

```
主伏笔：模拟器从哪来的
中伏笔：后山禁地那扇门后面是什么
转折伏笔：模拟第一次出错——因为有人对他隐瞒了信息
暗伏笔：痛是真的，说明模拟未必是假的，可能是真实发生过的平行人生
```

## 12 配角设计

```
镜像配角：同期天才师兄。他有天赋，主角有次数。
压力配角：杂役院管事，现实压迫的来源。
隐秘恩人：某个从不落井下石的人，后期转盟友。
对手：知道禁地秘密却想利用他的人。
```

## 13 关系情感线

```
无女主。主线放在师徒、同门、对手三组关系上。
```

> ⚠️ **原依据不成立，但结论仍可保留——理由要换。**
>
> 原话是「无女主是当前番茄的标签趋势」。本地 360 本样本查下来**不支持**这个说法：
>
> | 标签 | 全样本 360 本 | 玄幻/仙侠类 77 本 |
> | --- | --- | --- |
> | 无女主 | 14（4%） | 5（6%） |
> | 单女主 | 25（7%） | 3（4%） |
> | 多女主 | 41（11%） | 10（13%） |
>
> 无女主是**少数派**，多女主的书反而是它的两到三倍。所以不能拿「趋势」当理由。
>
> **真正站得住的理由有两条**：① 省笔墨——感情线是要章节预算的，前 30 章要冲追读率，每一章都得用在钩子上；② 对标书里确实有成功先例，《开局长生万古，苟到天荒地老》（608.1 万字，总阅读 115 万，样本内修仙轴第一）和《武道长生，不死的我终将无敌》（411.8 万字）都带无女主标签，说明这条路在「苟道长生」这个细分里是通的。
>
> **代价要认**：放弃无女主标签能覆盖的读者更多。如果后续想加，单女主比多女主更省笔墨。这是个取舍，不是个共识。

# 附录

## 附录 A：写作风格六条

1. 不用生僻词，不堆四字成语。「长生久视」改成「不会死」。
2. 短句为主。一句话说完一件事，别套从句。
3. 对话多于描写。番茄读者在通勤刷，大段景物描写是完读率杀手。
4. 章节标题用大白话，两个短句用空格切开，可以带梗。
5. 一章只讲一件事，章末那句话必须让人想点下一章。
6. 别解释设定。模拟器怎么运作不用说明，让读者从他用的方式里自己看懂。

**依据**：番茄头部和腰部是两种写法。头部《开局长生万古，苟到天荒地老》115 万阅读，章节标题是「第 7 章 我天生大力 还有一头祖传大黑牛」「第 9 章 女人只会影响我打铁的速度」「第 10 章 大家听到了啊 这人不讲道理」。腰部《长生：仙庭关系户下界摸鱼》207 阅读/章，标题是「第 4 章 长生久视」「第 8 章 玄策绯眉」「第 13 章 苦渡经」——「玄策绯眉」这种词，读者在列表页划过去根本不知道这章要发生什么。

## 附录 B：章节标题示例

```
第 1 章 扫了三年地 今天他不想扫了
第 2 章 第一次模拟 死在第七天
第 3 章 又死了 这回死得更快
第 4 章 原来那条路走不通
```

比「初启模拟，命殒禁地」这种好得多——读者一眼知道发生了什么，而且「又死了」自带幽默感。

## 附录 C：两条已否决的写法

**第一章就上模拟，不慢。** 数据：《开局模拟被打爆》第 1 章标题就是「登基称帝，人生模拟系统绑定」→ 1670 阅读/章；《开局长生万古》第 1 章「长生万古 开始加点」→ 修仙轴阅读总数第一；《天降玄碑》金手指拖到第 7 章 → 341 阅读/章，同行五分之一。番茄的读者是算法推过来的，通勤和睡前碎片时间刷，七天验证期只看追读率。第一章纯铺垫，不会有第二章。**担心爽点落空的解法不是往后拖，是让第一次模拟失败。**

**穿越可以有，但一句话带过。** 证据比原先说的更硬：不只是「100 本书名里出现 17 次」，番茄 360 本样本里**带 `穿越` 标签的有 205 本，占 57%**，是全样本第一高频标签（第二是都市 105 本 / 29%，第三是系统 88 本 / 24%）。而且两本模拟流头部书**都带穿越标签**。也就是说穿越不是「可以有」，是这个池子里的默认设置。它的真正用处不是随大流，而是**给「谨慎」一个来源**：穿越者没有靠山、知道自己是外来的、见过更大的世界，天然会算。但不要写穿越震撼，读者早免疫了——「我穿越了？这是什么世界？」这种桥段浪费前三章，正是《天降玄碑》那种死法。开篇写他已经是杂役、已经接受了、正在算怎么活下去。本土杂役也能解释「底层求生」，只是要多花笔墨。

| 第 4 章 | 还是惨，但他发现了规律——模拟只能推演他已经知道的东西。他知道的太少，所以怎么走都是死。于是他开始有目的地打听消息。 |
| 第 5 章 | 第一次模拟活过了一整天。他拿到一条具体的信息。用它，在现实里赢下第一场——很小的一场，但是第一次赢。 |

**为什么是「模拟没用」而不是「没有模拟」**：读者不是在看一个倒霉蛋受苦，是在看一个手里攥着彩票却一直不中奖的人受苦。前者只有同情，后者每一章都在等。《一年抽取一词条，模拟的也可以？》122.9 万字、51.3 万阅读、已出漫剧，整整十八年的凄惨生活——落黑帮、做苦力、凄凉，但金手指从第一章就在，只是它一直不出货。追读率差的就是这个「等」。

**附带的好处**：「死法一次比一次蠢」这条线天然好笑，而番茄头部的章节标题就是这个调性。凄惨期有了喜剧感就不苦了，读者反而追得动；纯写受苦，读者会累。

**唯一的硬约束**：如果最终要前三章完全不出现模拟，至少在第 1 章结尾给一个暗示（比如他昏过去时看见一行看不懂的字），别让读者在毫无预期的情况下连读三章苦日子。

## 附录 E：番茄 360 本实测基准

| 25% | 662 |
| **中位数** | **1104** |
| 75% | 1925 |
| 90% | 3144 |

**怎么用**：写到 15 万字时把自己的阅读/章 对进这张表。低于 662 说明开篇有硬伤，别靠加更硬扛；站上 1925 才算进入头部候选。

```

### ⚠️ 方法论警告：阅读/章 不能跨字数区间比

这个指标被书龄和长度严重混淆——它是**总阅读 ÷ 总章数**，老书的分母一直在涨，早期章节的阅读量会被后面几千章稀释。

看这三本就知道有多误导：

| 书 | 字数 | 阅读/章 | 总阅读 |
| --- | --- | --- | --- |
| 站中间抽两边，什么叫霸之意志呀 | 19.8 万 | **4812** | 42 万 |
| 开局模拟被打爆 | 19.2 万 | 1670 | 15 万 |
| 开局长生万古，苟到天荒地老 | 608.1 万 | **425** | **115 万** |

《开局长生万古》的阅读/章 只有 425，在表里几乎垫底，但它的**总阅读 115 万是样本内修仙轴第一**。用阅读/章 判它是「差书」会得出完全相反的结论。

**规则**：只在字数相近的书之间比阅读/章；跨区间要比总阅读。附录 C 里《开局模拟被打爆》对《天降玄碑》之所以成立，正因为两本都是 20 万字上下、90–100 章。

### 差异点复核：三样焊在一起确实没人做

样本里书名含「苟」或「杂役」的只有 2 本：《洪武苟神》（历史脑洞，696 阅读/章）和《开局长生万古，苟到天荒地老》（玄幻脑洞，425）。含「模拟」的 3 本已列在第 3 格。**模拟 × 苟 × 修仙 三者同时命中：0 本**——原判断成立。

## 附录 F：首章标题实测样本

同区间（15–25 万字）玄幻/仙侠类 28 本的真实第 1 章标题，按阅读/章 排序。这是附录 A 第 4 条和附录 B 的实证基础。

| 阅读/章 | 第 1 章标题 |
| --- | --- |
| 4812 | 霸之意志！ |
| 3407 | 混沌天帝，让我身化禁区？立仙庭，举世皆寂！ |
| 3144 | 窃蛋的古蛇 |
| 2955 | 师尊迫不及待的想吃掉你 |
| 2261 | 我这一生，如履薄冰 |
| 2117 | 今日方知我是我 |
| 1852 | 不要选截教 |
| 1789 | 出生 |
| 1772 | 退师！必须退师！ |
| 1670 | 登基称帝，人生模拟系统绑定 |
| 1392 | 哥布林喽啰、天赋树 |
| 1033 | 穿越太阳的我不堪忍受寂寞 |
| 985 | 元婴末路 |
| 823 | 人不在江湖好多年 |
| 781 | 众里寻他千百度，蓦然回首…… |
| 526 | 神明的傲慢，俯瞰众生，不容亵渎 |
| 449 | 一切的开始 |
| 363 | 姑娘，抽张牌 |
| 341 | 辞官买地，避世藏拙！ |

**一句话规律：标题要写「发生了什么事」，不要写「气氛怎么样」。**

排在上面的，全都在讲一件事：退师、不要选截教、师尊要吃掉你、登基绑定系统。读者一眼知道这章会发生什么。

排在下面的，讲的都是一种状态。「辞官买地，避世藏拙」（341）说的是主角想退隐——没有对手、没有冲突、没有意外。「一切的开始」（449）、「神明的傲慢，俯瞰众生」（526）也一样，都是气氛词。

**顺带修正附录 A 第 4 条的说法**：不是「必须大白话」。「窃蛋的古蛇」「元婴末路」都不算白话，照样排在前面。大白话只是**写事件最省力、最不容易写砸的办法**，所以本书还是用它——但真正的标准是有没有事。

本书拟用的「扫了三年地 今天他不想扫了」符合：后半句是一个决定，是事件。
