## 一、一句话

**玄丘宗杂役陈九得了一件东西：睡一夜，活一世。** 每一世都从今夜开始，他在里头怎么活、怎么死，醒来全记得，身上的伤也是真的。三千世之后，天下没有他没见过的招、没算过的人——他一出手，就是无敌。

书名：《杂役模拟三千世，一出手就无敌》（暂留，待作者另裁）。番茄 · 玄幻脑洞 · 模拟流 · 1100 章 × 约 2200 字。

## 二、这本书卖的是什么

**模拟即正戏。** 正文六到八成发生在模拟里：他在里头拜师、学剑、被人追杀、娶妻、称雄、老死，一世一世地过。现实那一头只有两件事——**把里头学到的拿出来用，一出手就压死人；以及藏住身上的伤。**

四个爽点，按出现频率排：

| 爽点 | 形状 | 出处 |
| --- | --- | --- |
| **我见过你这一招** | 里头死在这人手上七回，现实里第一次照面就把他破了 | 三千世的记性 |
| **活得久带得回好东西** | 里头活了六十年、练成一门剑，醒来最多带回一样——但那一样够他在现实里横 | 机制第四条「最多带回一样」 |
| **伤被人看见** | 醒来脖子上一道刀口，同屋的人问他昨夜去了哪 | 机制第三条「回声」，全书的曝光钩 |
| **算破天** | 后期他算的不再是自己，是一城、一国、一天下，最后是天本身 | 真相 |

**不卖的**：抽卡、色阶天赋、等级条、氪金、后宫。奖励只有一种来路——**他在那一世活成了什么样**。

## 三、主角

**陈九**，十六岁，玄丘宗杂役院三年。十三岁那年流民队里被宗门收进来，测出下品杂灵根，只配扫地挑水。

- **本事**：记性好，肯算，不贪。三样里「不贪」最要紧——它是他跟前一任持有者唯一的区别（见第六节）。
- **毛病**：太惜命，起手总慢半拍；对人狠不下心，里头死过的人他会记很久。
- **要的东西**：先是活下去；然后是不再任人宰割；再然后是弄明白这东西是什么；最后是「天不算人，人自算命」。
- **说话**：短句，不解释，爱用「我见过」「这回换个法子」。不说狠话，狠话是别人替他说的。

配角与反派见 `04-人物.md`。

## 四、金手指：「三千世」

它自己不报名字。前二十章正文只叫它「那东西」「梦」；第一次在面板上现出「三千世」三个字要到卷二末。

**四句话说完**（细则全在 `02-模拟器机制.md`，这里不复制数字）：

1. **入睡即入世。** 真睡着了它才问；应了，这一夜他从今夜起活一辈子，活到死为止，中途出不来。
2. **里头是真的。** 它算的是这方天地真实的天机，不是他的想象。他在里头读到的功法是真功法，杀他的人明天也真会杀他。只有三样算不准：比他高两个大境界以上的人、天命司的人，和它自己——**里头没有它**。
3. **死了要还。** 里头怎么死的，醒来身上就怎么疼，伤痕挂几个时辰。死得多了，留在里头的那些「他」会回头找他。
4. **最多带回一样。** 每一世醒来，面板最多列三样他**死时确实拥有**的东西——一门练熟的功法、一截修为、一样体质、一件握在手里的物；他最多带回一样，也可以三样全不选，未选项当场消失。**活得越久、成的事越大，能带的越好；死在头一天，什么都没得带。**

**呈现**：它开口用 `【】`，一律短句、文言味，一章面板不超两百字。**里头也用 `【】`**：从始到终每一段都是 `【你……】`，里头句不计入面板字数；现实段第三人称「他」（2026-09-25 作者裁，细则归机制 0.2、0.3）。

## 五、世界（一段话，细则归 `03-世界观.md`）

修仙界九境：炼气（九层）→ 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。境界名用读者已经认识的，正文一句都不解释。

玄丘宗是东荒青州一个二流宗门，杂役院在山脚下。宗门之上有州、有十几个大宗、有山下的凡人王朝；再往上，有一个谁都不知道的衙门——**天命司**。天命司不属于任何宗门，它管的只有一件事：**人不许算命**。

## 六、真相（作者知道，读者不知道）

> ⚠️ 剧透。前六卷任何角色不许说破。揭晓节奏见第八节。

**上古有人造了一件「算天盘」，让人能算自己的命。天不容，把造盘的人抹了，盘碎成残片散落人间。「三千世」是其中最大的一片。**

- 天命司是天道在人间的手。它不管善恶、不管修为，只杀一种人：**算得太多的人**。持有残片的人算得越多，身上天机反噬的痕迹越重，天命司照着痕迹找人。
- **三百年前，「三千世」的上一任持有者就在玄丘宗。** 他是开山祖师的师弟，算到两千多世，被天命司抹了——抹得连宗门族谱都没有他。杂役院那些没人说得出来由的老规矩（夜里不许点灯、井边不许过夜、每月初一杂役全体上山扫墓）全是他留下的，**是留给下一个持有者的路标**。
- 上一任败在**贪**：他在里头活成了什么样，就非要把那一世整个带回来。带得越多，反噬越重，痕迹越显，天命司来得越快。**「最多带回一样」不是它的规矩，是上一任临死前替下一任加的锁。**
- 「三千」不是修辞。**算尽三千世，可窥天机；算尽三千世，天亦不容。** 三千世之后他能算的东西里，包括天道自己。

**揭晓节奏**：卷二末第一次听见「天命司」三个字 → 卷四知道「算天盘」→ 卷五遇见别的残片 → 卷七得知上一任是谁、怎么死的 → 卷八算破天。

## 七、结局

**他算尽三千世，算出了天命司的命，然后把它结了。** 从此这方天地，天不算人，人自算命。他站在最上头，没有跌下来——番茄读者要的是这个。

代价不落在修为上，落在人上：三千个在里头死过的「他」，每一个都有一辈子。最后三章他把他们一个一个送走。**第 1100 章的最后一句，接的是第 1 章第一句。**

## 九、红线（写任何一章前对一遍）

| 红线 | 一句话 |
| --- | --- |
| **模拟即正戏** | 一章里模拟内部的文字少于一半就是写歪了（面板与现实衔接章例外，全卷不超四分之一） |
| **里头是真的** | 模拟里读到的功法、遇见的人、发生的事，除机制「真：它算的是真天机，只有三样算不准」列明的三样之外，一律照真的写，之后现实里要能对得上 |
| **最多带回一样** | 一世最多带回一样，也可以三样全放弃；必须是死时确实拥有的。不许攒、不许存、不许「其实还留着」 |
| **死了要还** | 里头死了，醒来必有回声。没有回声的死等于没写死 |
| **不抽卡** | 没有随机天赋、没有色阶、没有等级、没有模拟点。选项成色只跟「那一世活成了什么样」挂钩 |
| **里头用【】** | 里头每一段是 `【你……】`，现实段写「他」。它开口的面板句短，一章不超两百字，里头句不算 |
| **不解释** | 旁白不解释机制。读者从他怎么用、怎么死学会规则 |
| **不现代** | 概率、数据、效率、信息、状态、资源、概念这类词不进正文，换法见术语表 |
| **不自创** | 大纲与设定里没有的人名、地名、数字、境界说法一律不写，填「待确认」回报派单通道 |
