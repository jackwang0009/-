## 零、它在正文里长什么样

### 0.1 名字

它不报名字。正文前二十章只叫「那东西」「梦」；面板上第一次现出 **`【三千世】`** 三个字在卷二末（第 190 章前后，由卷二纲定）。此前面板不带抬头。

### 0.2 一世的五拍（顺序不许换）

| 拍 | 写什么 | 面板 |
| --- | --- | --- |
| **入** | 他真睡着了。它问，他在心里应「是」 | `【是否以此刻为始，模拟此生？】` → `【第 N 世 · 始】` |
| **世** | **第三人称场面。** 从今夜这一刻起，他活一辈子。跨年用正文小标推进（「第三年春」「他三十岁那年」），不用面板 | 无 |
| **终** | 他死了，或寿终 | `【第 N 世 · 终 · 享年 X】` `【死于：……】`（死因一句话） |
| **带回** | 三行选项，全是他**死时确实拥有**的东西。他选一样，另两样没了 | `【可带回一样】` 三行 → `【已带回：……】` |
| **醒** | 现实里天亮了（死在头几天的短命世，他可能半夜就醒）。回声先到：疼、伤痕、虚弱。然后这一天照常过 | 无 |

**面板一章不超两百字。** 死在头一天的短命世只要「始」「终」两行。选项那三行是全书最常出现的面板，每一行不超十二个字。

### 0.3 三条呈现红线

1. **模拟内部一律第三人称。** 写「他」，不写「你」。面板里 `【】` 是它在说话，不受此约束。
2. **面板不替叙事。** 他在里头怎么活的、怎么死的，要用正文的句子写出来；面板只是收尾的一个锚。
3. **模拟内部的文字一章不少于一半。** 全卷可以有不超过四分之一的章例外（现实衔接章、曝光章、大比章）。

### 0.4 不许出现的东西

模拟点、能量、经验、等级、色阶天赋、随机抽取、进度条、冷却、商店、每日刷新。**这本书的奖励只有一种来路：他在那一世活成了什么样。**

## 一、六条规则

### 1. 入世：真睡着才问，一夜一世，中途出不来

- **只在他真睡着时问一次。** 打坐不算，装睡不算。不应，这一夜就是一夜好觉。
- **一夜只能一世。** 应了就进去，从今夜这一刻起活到死。里头时间照常流，现实只过一夜。
- **世数按夜数计。** 应了一夜就是一世，死在头一天也算一世；一章里写了几夜就是几世，不许把几夜并成一世记。卷纲的世号、全书大纲第三节的累计世数，都按这一条数。
- **里头活得短，现实里醒得早。** 里头几十年，现实一觉到天亮；死在头几天，他可能半夜就醒，伤痕就挂在黑里——同屋的人起夜看得见。醒了它这一夜不再问（一夜一世）。不写的夜就是没应，卷纲不必逐夜交代理由。
- **中途出不来。** 里头被人囚了三十年，他就得在里头过三十年。这一条是全书心魔线的根，不许松。
  > 卷三第 240 章前后他学会「醒」——在里头主动断掉这一世。代价：**那一世什么都带不回**，且回声照结。学会之前不许有任何人在里头「醒过来」。
- **现实里被人叫醒、碰醒，那一世当场中断。** 面板 `【此生中断】`，无带回，记得到中断为止。他睡着的时候像死人一样叫不醒，同屋的人会注意到——这是卷一的一条曝光线。
- **他带着全部记性进去。** 每一世他都记得前面所有世。所以第二世的他比第一世聪明，第三十世的他已经把杂役院每个人的脾气摸透了。这是全书成长的真正来源。
- **里头没有它。** 模拟里不能再模拟。进了里头他只有自己的脑子。

### 2. 真：它算的是真天机，只有三样算不准

**里头是真的。** 他在里头读到的功法是真功法，学到的招式是真招式，杀他的人明天真会杀他，藏经阁第三排第七格真有那本书。所以他在里头学到的东西，现实里全能对上——**这是「一出手就无敌」成立的机制根据**。

**三样算不准，其余全准：**

| 算不准的 | 里头怎么表现 | 为什么 |
| --- | --- | --- |
| **比他高两个大境界以上的人** | 那人在里头按「最像的样子」行事，可能错。他炼气时，金丹以上全在雾里；筑基时，元婴以上；以此类推 | 高境者遮天机。这一条随他修为涨而松，**是他必须在现实里修炼的唯一硬理由** |
| **天命司的人** | 不论境界，一律在雾里 | 他们本身就是天机所遮 |
| **它自己** | 里头没有它；它也算不出任何关于它自己、别的残片、算天盘来历的事 | 它不能算它自己 |

「大境界」指九境里的一级（炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫）。炼气九层不算境。

> **落笔口径**：在雾里的人，写他们**做了让人意外的事**，不写「他看不清」。雾不是特效，是他吃了亏才回头想明白的东西。
>
> **面板上 `【死于：不知】` 只写给天命司的人。** 他们是天机所遮，它连死因都算不出。比他高两个大境界的人杀了他，面板照写那人的名字或身份（`【死于：卧石长老】`）——它认得那个人，只是没算到那人会动手。「不知」是全书留给天命司的一个记号，不许挪给别人用。

### 3. 回声：死了要还

里头死了，醒来三样一起到：

- **疼是真的。** 怎么死的怎么疼。被砍头醒来脖子像断过，烧死醒来皮下火燎。
- **伤痕会显。** 致命伤那一处在身上显出来，**挂几个时辰，最长一日**。死状越惨挂得越久。同屋的人看得见——**全书曝光钩的来源**。
- **虚弱一日。** 那一天手脚不听使唤，干活慢半拍。

**没死就没有回声。** 寿终正寝醒来身上干干净净，只是累。

**每一次死留下一点「他」在里头。** 前两卷是噩梦；卷三起偶尔听见他们说话；卷六他们回来找他。不设数字、不设阈值，**它是累加的，而且没有任何东西会提前警告**。

### 4. 带回一样：只能带他死时确实拥有的

每一世醒来，三选一，选完另两样当场没了。**不许攒、不许存、不许「其实还留着」。**

| 类 | 是什么 | 能带回来的条件 | 例 |
| --- | --- | --- | --- |
| **术** | 一门功法或招式，**身体记得** | 那一世**练成了**（不是读过、不是会背） | `【青岚剑法 · 十二式】` |
| **修为** | 一截修为直接落到身上 | 上限：**不许跨大境界**。炼气最多带一层；筑基以上最多带一小段。大境界的突破必须他自己在现实里过 | `【炼气三层】` |
| **体质** | 身体上一处改变，不可逆 | 那一世身体确实变了（洗过筋、淬过骨、中过毒练出的抗性） | `【寒毒不侵】` |
| **物** | 一件握在手里的东西 | 死时**确实在手里**；它从那一世借过来。**这一类反噬最重**——伤痕挂三日不退 | `【一柄断剑】` |

**四条硬的：**

1. **必须是新的。** 现实里已经有的东西不进选项。
2. **必须是死时拥有的。** 二十岁练成一门剑、五十岁被废了功、六十岁死——那门剑不在选项里。
3. **死在头一天，什么都没得带。** 他什么都还没有。
4. **成色由「活成了什么样」决定。** 活六十年、当上一宗之主的那一世，三个选项都是好东西；活七天被打死的那一世，三个选项是「三块灵石」「半套扫地的本事」「一件破袄」。**不是抽的，不是随机的，读者要能指着上一段说出「这次给得好是因为他这一世干成了什么」。**

**例外：带不走的东西。** 极少数时候，第三行会放一样带不走的东西——一个名字、一处地方。他选了也带不回，这一行是它在**指**，不是在给。它不算带回，不算四类之一，也不占那一世的三选一；每出现一次都要在该卷伏笔账登记。第一次是卷一第 14 章的 `【那新来的名字】`，归卷六「三千个他」。前六卷不许任何人解释这一行是什么。

**「记得」是白送的，「身体记得」不是。** 他在里头练了六十年剑，醒来脑子里全记得：怎么起手、怎么变招、每个对手的破绽。**但手跟不上**——现实里他还是那个杂役的身子。「术」这一类带回的是身体记性，一次只带一门。**所以他知道的永远比他能用的多得多，这是他前六卷所有「差一点」的来源。**

### 5. 魂载：一夜里活得太久，神魂吃不住

一夜一世，可里头一世可以是七天，也可以是九十年。**神魂一夜能承载多少年，看境界：**

| 境界 | 一夜承载 |
| --- | --- |
| 炼气 | 十年 |
| 筑基 | 三十年 |
| 金丹 | 一百年 |
| 元婴 | 三百年 |
| 化神 | 一千年 |
| 炼虚 | 三千年 |
| 合体 | 一世不限 |
| 大乘 | **一夜多世** |

**超载的代价：里头每多活十年，醒后一日不能入梦，且那一日显老态**——白发、手抖、眼花，天黑才退。炼气的他在里头活到七十岁，醒来五天不能入梦、五天白发。**老态是天机反噬的一种，跟伤痕一样会被人看见。**

**超载太多伤神魂**，不是歇几天就好。卷六心魔爆发的机制引子就在这里。

> 这条是刹车。没有它，他卷一就能一夜活六十年、第二天就带回一门大成的剑法。有了它，**早期每一次长命世都是事件**——他得先在现实里把修为提上去，才敢在里头活得久。这也是「模拟即正戏」这条路上唯一能让现实修炼有分量的东西。

### 6. 天机反噬：藏不住

伤痕（第 3 条）和老态（第 5 条）合称**天机反噬**。它们有三个用处，按卷递进：

| 卷 | 反噬是什么 |
| --- | --- |
| 一、二 | **同屋的人看得见。** 他得解释脖子上那道口子 |
| 三、四 | **会望气的修士看得见。** 他身上有一层别人没有的灰气，算得越多越浓 |
| 五起 | **天命司照着它找人。** 灰气浓到一定程度，他们就来了 |

**累计越多越难藏。** 前一百世伤痕挂几个时辰；五百世后挂一日起；两千世后不退。不设中间刻度，各卷纲自己定本卷的口径，但**只能往重写，不许往轻写**。

**痕迹跟着他进里头。** 他进去时的身子与现实一致（第 1 条），身上的伤痕、老态、灰气也一并带进去。里头的修士望不望得出，按上表那一卷的口径；里头的天命司**贴身擦过就认得出**，不论他攒了多少——但也只在贴身擦过时，他们不会为他远道而来。卷一第 18、60 章那个「死于：不知」就是这么来的（世界观 5.4）。

## 二、为什么这么定

| 规则 | 解决了什么 |
| --- | --- |
| 一夜一世、真睡才进 | 他睡着时像死人，夜里是他最弱的时候。危险与曝光都从这里来 |
| 中途出不来 | 坏命也得活完。心魔线有根，读者替他怕 |
| 里头是真的 | 他学到的东西现实里全能用，「一出手就无敌」不是嘴上说的 |
| 三样算不准 | 长老、大能、天命司永远有意外，他永远不是全知 |
| 带回一样且必须拥有 | 奖励与「怎么活」焊死，抽卡文的通胀进不来 |
| 魂载表 | 早期活不了太久，现实修炼有分量，成长看得见 |
| 反噬藏不住 | 全书唯一贯穿的外部压力，通向天命司 |

## 三、玩法演进（防 1100 章重复）

| 卷 | 玩法 | 新加的一样东西 |
| --- | --- | --- |
| 一 | **活过这个月。** 前十世全死在一个月内，死因就是情报 | 无 |
| 二 | **活得久。** 里头几十年练功，带回「术」 | 老态第一次出现 |
| 三 | **借命。** 以别人的血为引，那一世从**那个人**的此刻开始活 | 「醒」；借命世留下的是别人的心魔 |
| 四 | **算局。** 入世前设一个「若」（若明日城门失守），看一城一国百年 | 一夜一国 |
| 五 | **对算。** 别的残片持有者也在算他，两边都在雾里 | 残片相克 |
| 六 | **不敢入。** 心魔回来，四十章一世不入 | 无 |
| 七 | **算不动。** 天命司在雾里，他需要三千才看得见 | 上一任留下的锁 |
| 八 | **一夜三千世。** 并行 | 解锁：带回全部 |

**卷三「借命」与卷四「算局」是两条新机制，各自在对应卷纲里定细则，本文件只登记它们存在。** 定之前不许在正文里出现。

## 四、真相侧的机制（作者知道，读者不知道）

> ⚠️ 剧透。前六卷不许任何角色、任何旁白点破。

- **「带回一样」是上一任加的锁，不是它原本的规矩。** 原本一世能带回全部。上一任带得太多，反噬太重，天命司三百年前找到他。他临死前把锁加上，留给下一个人。
- **卷八他解开这道锁。** 三千世的东西一夜全部带回——这是算破天的力量来源，也是全书反噬的顶点。天命司当夜就到。
- **心魔不是病，是那些「他」。** 每一世死掉的他都是真活过一辈子的人。卷六他们回来，不是为了害他，是问他一句话：你打算怎么安置我们。卷八最后三章他一个一个送走。
- **它算不出自己**这一条是真的，不是设定上的偷懒——它是残片，不全，所以照不见自己。别的残片能照见它。卷五那一场对算，对手看得见他，他看不见对手，就是这个道理。

## 五、写作时的自检

每写一场模拟戏，对一遍：

- [ ] 这一世从**今夜这一刻**开始吗？他进去时的身子、修为、手里的东西，与现实此刻一致吗
- [ ] 里头有没有出现它自己、有没有再模拟一次
- [ ] 比他高两个大境界以上的人、天命司的人，有没有写得太准
- [ ] 他怎么死的，写清了吗？醒来的回声写了吗——疼在哪、伤在哪、谁看见了
- [ ] 这一世活了多少年？超魂载了吗？超了几天不能入梦、老态写了吗
- [ ] 带回的那一样，是他**死时确实拥有**、且**现实里没有**的吗
- [ ] 放掉的两样写出来了吗
- [ ] 面板不超两百字？模拟内部文字不少于一半？
- [ ] 这一世的玩法，和上一卷重复了吗
