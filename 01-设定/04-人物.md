## 零、总规矩

**硬约束：无女主，不写感情线。** 全书的笔墨只给三组关系。

| 关系 | 谁 | 承担什么 |
| --- | --- | --- |
| **师徒** | 老周 | 情感。全书唯一让读者掉眼泪的地方 |
| **同门** | 谢无咎 | 参照。读者用他来量云昭走到哪一步了 |
| **对手** | 柳寒山 | 悬念。他是主伏笔的人形载体 |
| （压力） | 赵堂 | 现实的重量。前 180 章的地心引力 |

**取名规则**（写次要人物时对一遍）：两到三个字，不用生僻字，不用四字雅号。读者在手机上刷，记不住"玄策绯眉"那种名字。同一卷里的名字不能声母相同（"马冲/毛冲"这种一定会记混）。

**三千个云昭一律用特征称呼，不用序号**（已定稿）：叫"扫地的那个""成魔的那个""活到元婴的那个""死在纸条上的那个"，**不叫"七号""三十九号"**。序号读者记不住，特征名一眼就知道是谁。卷七、卷八两卷都按这条走。

## 一、云昭（主角）

| 项 | 值 |

| 身份 | 青玄宗杂役院杂役，扫地三年 |
| 年龄 | 开篇 16 岁（13 岁上山，扫地三年）。第 1100 章 66 岁，全书共 50 年（`06-年表.md`） |

| 一句话外貌 | **瘦，个子不高，手心一层扫帚磨出来的黄茧。他总是低着头，可眼睛一直在数东西——数人、数步子、数你手里那把剑离他还有多远。** |

### 说话方式

短句，平铺，不带情绪。**他几乎不说狠话，狠话都是别人替他说的。** 他最常干的事是把对方的话重复一遍，然后接一句自己的判断。

口头禅：

```
"我算过了。"
"还差一点信息。"
"这次不行。我知道我会输。"
```

后期版本（卷五起）：

```
"我死过三千次了，你才死一次。"
```

**写他的时候注意**：他不解释。别人问他为什么知道，他答"我算过了"，然后就没了。读者的爽感来自"他早就知道了而对方还不知道"，一解释就泄气。

### 核心欲望

- **表层**：活下去，往上爬。
- **深层**：他要的不是变强，是**再也不用赌**。他受不了的是"不确定"这三个字。

这一条决定了他所有的行为逻辑：他宁可多死五次换一条准信息，也不肯凭感觉出一次手。**这是"主动的苟"和"怕事"的分界线。**

**它的反面写在他的丹上。** 第 460 章结丹，丹圆得干干净净——**因为他从来不让自己过不去：他算，他往前走，他不回头。** 这不是夸他，**这是他的毛病**，而这笔账要到第 780 章才还（见谢无咎那一节「裂欠到了元婴」）。

### 怕什么

- 不怕死。死太多次了，疼归疼，不怕。
- **怕"不知道"。** 具体表现：被逼在没算清的情况下出手时，他会失态——这是全书唯一能让他失态的东西。
- 怕自己的判断害死别人。（第 780 章成真）
- 一个他自己都不承认的：**怕停下来之后，发现自己什么都不是。**（第 1100 章的答案）

### 他为什么比别人快十倍（全书题眼，写他的每一章都记着）

模拟里过掉的年月**不算他的现实年龄**——现实里只过一息。但**走过的路算数**。别人拿十年试出来的弯路，他在模拟里全走完了，现实里只走对的那一条。

> **他不是天赋高，是从来不走错路。**

所以他的耗时是理论最短值：常人到元婴要 265 年往上，他 25 年（`06-年表.md` 第三节）。

**这一条是拿来写人的，不是拿来对数的。** 它同时解释了他为什么那么怕"不知道"——一条没走过的路，就是一条他没法保证不走错的路。**他的谨慎不是性格，是他这套本事唯一的使用说明。**

### 化神的代价（第 1068 章，已定稿）

化神没有瓶颈，只有价钱——化神要拿一样东西去换，换什么自己挑（`03-世界观.md` 第二节）。

**他挑的是：从此再也算不了自己。**

这一下把他的弧光从**姿态**变成了**处境**。原来"第一次在没把握的情况下出手"是他选的；现在**不是他选择不算，是他没得算**。第 1081 章关掉模拟器那一手，是一个真的睁眼瞎做出来的决定。

**更狠的一层**：他见过蒙洪——第三个持有者，**能算别人，算不了自己**（卷五 541–580）。他挑这一样，等于亲手把自己变成了蒙洪。这一处不要点破，让读者自己想起来。

### 退场

不退场。第 1081–1095 章关掉模拟器，代价是失去所有模拟得来的东西，修为跌回筑基。

**寿元这笔账要算给读者看**：化神不按年算，筑基只能活 150 年。他从"不按年算"跌回"150 年"——**这才是关掉模拟器真正的价钱**，比"修为跌回筑基"这句话具体得多。

第 1096–1100 章回青玄宗扫地。

全书最后一句回到第 1 章的扫地，闭环：

> 新来的杂役问他："师兄，你会什么？"
> 他说："我什么都不会，但我死过三千次。"

## 二、谢无咎（镜像）

| 项 | 值 |
| --- | --- |
| 身份 | 和云昭**同一天上山**的天才。谢家嫡子，附庸青玄宗的修真世家送上来的。他测出灵根进内门，云昭进杂役院扫地——**"师兄"这两个字是身份，不是年纪** |
| 年龄 | **和云昭同岁**：同一天上山（距第 1 章三年），那年都是 13 岁，开篇 16 岁。**上山一年后就筑基，落在 −2 年、14 岁**——163 年里的第二个（`06-年表.md`、`03-世界观.md` 2.1）。第 780 章死时 41 岁 |
| 名字来历 | 他爹取的，卦辞里的词，意思是"不会有错"。**这是全书最大的反讽**——他最后死在唯一一件不合逻辑的事上 |
| 一句话外貌 | **白衣服，一天换两次，袖口永远没有一点灰。他站在满是土的杂役院里，像一个走错地方的人。** |

### 说话方式

直，不绕。**他不是故意刻薄，他是真的没想过别人会难受。** 他习惯用问句羞辱人——而他自己不觉得那是羞辱。

口头禅：

```
"你叫什么来着？"      ← 前期。他是真的记不住
"这有什么难的？"
"你再算一次，我等你。"  ← 卷四之后。同一个口气，从羞辱变成信任
```

**"你再算一次，我等你"这句话是他弧光的载体。** 第 26 章他说的是"你算啊，我等着看你出丑"；第 430 章他说的是同样八个字，意思完全反过来了。中间不需要任何一句解释。

### 核心欲望

**他要证明自己配得上这份天赋。** 天赋是白给的，他一辈子都在还这笔白给的债。

### 怕什么

**怕自己其实只是运气好。** 遇到云昭之后这份恐惧被具象化了：一个屁天赋没有的人，靠死了三千次追上来了。云昭越强，他越慌——不是怕输，是怕自己那点天赋原来根本不值钱。

### 退场

**第 780 章。全书情感最高点。**

关键设计：**他不是没算清才挡的，他是算清了才挡的。** 全书只有这一次，另一个人也在算——而云昭算不到他，因为"谢无咎会怎么选"这件事，从来不在云昭的信息范围内。

死前那句话不要煽情，用他一贯的口气：

> "这有什么难的。"

云昭随后在模拟里救成 37 次，现实里一次都没成。**这是他唯一算不准的事。**

### 他的死是云昭入元婴的台阶（定稿时间线，以本节为准）

| 章 | 发生了什么 |
| --- | --- |
| 460 | 云昭金丹。**这时他还活着，云昭的丹是圆的** |
| 658 | 云昭金丹圆满 |
| 753–762 | **三次冲元婴，全部失败。** 问他哪个才是自己，他答不上来 |
| 771–779 | 决战。云昭还是金丹圆满 |
| 780 | **他死 → 云昭当场入元婴**（第一道坎：认出**哪一个是我**） |
| 956 | 云昭元婴圆满（第二道坎：认下**三千个都是我**） |

**他死的时候云昭是金丹圆满，不是元婴。** 这一点定死了：753–762 连冲三次都没上去，771–779 那场决战云昭也是拿金丹圆满打完的——**一世的模拟上限、一天 8 次配额，就这副家当**。

**但那道裂没能留在他丹上——它欠到了元婴。**（`02-模拟器机制.md` 四之一已补上这座桥）

云昭的丹是圆的，从第 460 章结丹那天起就是圆的。**圆得干干净净，是因为他从来不让自己过不去：他算，他往前走，他不回头。这正是他的毛病。**

「丹上有裂 = 心里过不去的事」这条规矩先在别人身上立住——卷五那些互相残杀的持有者、卷六那些拿别人年岁活着的魔门人，丹上都有裂。读者先见够了带裂的丹是什么下场。

**然后第 780 章，那件他过不去的事终于来了。可他同一刻入了元婴。** 该在金丹上裂的那一道落不下去，**于是它变成了元婴的坎**。

**这就是他卡 176 章的机制原因**：不是文学上的说法，是账上真欠着一笔——**该在金丹上裂的，欠到了元婴。**

**为什么这一死就能破关**：元婴分两道坎，第一道是"**认出哪一个是我**"。他 753–762 连冲三次都失败，是因为答不上这道题——第 620 章他刚知道有三千个自己，谁都可能是他。**而唯一能替他认出"哪个才是云昭"的那个人，第 780 章死了。**

正因为死了，他才认出来了：**是这一个。是让谢无咎死掉的这一个。他是踩着谢无咎上去的，而且他知道。**

**内容上还有一层：这个答案只答对了一半。** 剩下那一半是第二道坎"**认下三千个都是我**"——要等卷七三千个自己一个一个见过来、老周第 950 章留下真相之后，才补得上。

**两层叠起来，就是 780 到 956 这 176 章整整一卷。**

**这一场突破不要写成爽点。** 写成他这辈子最不想要的那一次进步。

（卷七第 781–950 段落里，门后世界还活着一个谢无咎——这一刀要在卷七再补一次。**他是云昭"认得自己"这一关最过不去的地方**。）

## 三、赵堂（压力）

| 项 | 值 |
| --- | --- |
| 身份 | 杂役院管事 |
| 年龄 | **四十七岁**。炼气九层卡了二十年，这辈子上不去了 |
| 名字来历 | 名字普普通通，因为他就是个普通人。**他不是恶霸，他是一个被卡住的中年人**，把气撒在比他更低的人身上 |
| 一句话外貌 | **胖，脖子上一圈汗。腰上一串钥匙——那串钥匙响到哪儿，杂役院就静到哪儿。** |

### 说话方式

带笑，越笑越狠。**他从不直接骂人，他"讲道理"。** 这比骂人难受得多，也真实得多。

口头禅：

```
"我这是为你好。"
"规矩就是规矩，你说是不是？"
"你去问问，谁不服？"
```

**写他的时候注意**：不要把他写成脸谱化的恶人。他有一段要让读者理解他——**第 168 章前后**，云昭从老周和崔虎嘴里凑出赵堂的老底：他年轻时也是个杂役，也想过往上爬，也被人踩过。理解归理解，账还是要算。

**这一段必须这么写，不能让云昭在模拟里"看见"赵堂的过去**——模拟只能推演他已经知道的东西（见 `02-模拟器机制.md` 第 5 条），二十年前的事他不可能知道，模拟器只会给他编一个。**先打听，再拿模拟去验证赵堂现在会怎么反应**，这才是合规的用法。顺带又演示了一次全书的核心：**信息就是战力。**

### 核心欲望

**他想被人当回事。** 就这么小。他的权力只够在杂役院里当回事，所以他死死攥着那串钥匙。

### 怕什么

- 怕上面看见他没用。
- 怕有一天钥匙不响了，没人再怕他。
- 后期加一条：**怕云昭。** 不是怕挨打，是怕对方每一步都合规，让他连喊冤的地方都没有。

### 退场

**第 180 章，不杀。** 撸掉管事，发回杂役院扫地——扫云昭扫过三年的那条道。

**留着他，是因为他是活证据：云昭做事不越线。** 后面还有三次回声：

## 四、老周（隐秘恩人 / 全书最重要的装置）

| 项 | 值 |
| --- | --- |
| 身份 | 杂役院最老的杂役。哑巴 |
| 年龄 | **第 1 章 68 岁**（12 岁上山，扫了五十六年，上山的年头比赵堂的师父还早）。第 950 章死时 **106 岁**——从哑那天算，他守了 79 年（`06-年表.md`） |
| 名字来历 | 没人知道他姓什么，杂役院叫了几十年"老周"。他自己写过一次自己的名字，写到第二个字就抖没了 |
| 一句话外貌 | **驼背，右手三根手指是弯的——不是老化，是每次想写下真相时自己抖折的。** |

### 他为什么哑（最终定稿，以本节为准）

**不是天生哑，也不是谁下的手，更不是他选了哑。**

四十一年前（`06-年表.md` −41 年）他 27 岁，挑水路过后山那条没人走的道，**撞见门开了一条缝，柳寒山从里面走出来**。柳寒山没杀他，给了他一个选择：

> "你现在走、忘掉，还能说话；你要是想知道我是谁，从今天起就说不出去了。"

**老周问了。当天他哑的。**

**禁制是那样东西自带的机制**：知情而又不是持有者的人，就是说不出口。这一条对谁都没有例外，也不需要谁来施法——**所以他选的不是"哑"，是"知道"，哑是附带的价钱，而这个价钱事先明明白白告诉过他。** 他能点头摇头，能比划，能写几个字，一到关键处就写不下去。

**比"他哑了"更要紧的是他哑之后干了什么**：他没有下山，也没有装作没看见。**他留下来扫那条道，等下一个持有者。** 一等四十一年。**哑是他付的钱，留下来才是他这个人。**

他会写字，而且字写得意外地好——说明他年轻时读过书，不是生下来就扫地的。这个细节要在第 21 章登场时一笔带过，读者到卷七才会反应过来。

**这是全书最好用的装置：唯一知道真相的人，偏偏说不出来。** 真相能一点点漏，永远漏不完。

### 他进过那扇门（本档案原来缺这一条，卷三大纲一直在用）

他不是只在门外看了一眼。**门里那间石屋他进去过。**

他看见的和云昭第 320 章看见的是同一样东西：一具穿老式杂役服的遗骸，坐着，手里攥着一片东西。他做了两件事：

1. **掰下那半片带走**——四十年后塞给了云昭（第 60 章卷末那一下）。另一半留在遗骸手里，第 319 章两片对上。
2. **在石壁上写了四个字：「别死太多」。** 第 320 章云昭认出那是他的笔迹——第二个字最后一笔总要往上挑一下，扫了三年地的人见过太多次。

**所以那四个字不是遗言，是留言。** 上一任持有者死在 −289 年，老周 −68 年才出生，两个人从没见过面（`06-年表.md`）——他写那四个字，写的是给**下一个人**看的。**而他写的时候已经说不出话了：这四个字是他能留下的全部。**

**哪一天进的，已定稿：就是四十一年前那一天。** 柳寒山从门里走出来、给了他那个选择、他问了、当天哑掉——**门还开着，他跟了进去。**

**所以那一天是一个完整的闭环**：撞见 → 被告知代价 → 他问了 → 哑 → 跟进门 → 从遗骸手里取走半片残片 → 在石壁上写下四个字 → 出来，留下扫那条道，等下一个持有者。**一天之内他把这辈子剩下的四十一年全部决定完了。**

对应的卷三收束在 `02-大纲/03-卷三-内门.md` 卷末钩子：云昭跑回杂役院问"那扇门，你进去过？"——**老周点头，然后摇头，摇着摇着又变成点头。**

### 说话方式（这一格是全书最需要设计的）

他不说话。他有三种"语言"：

**1. 点头 / 摇头** —— 只能回答是非题。

云昭因此被迫学会**把所有问题拆成是非题**。这是老周给他最大的东西，比任何一条情报都值钱——第 4 章"有目的地打听消息"、卷二"只模拟下一步"、卷五"拆解持有者规则"，全都是这一手的延伸。

**2. 写字** —— 一次最多四五个字。写到关键处笔就抖，纸就破。

第 24 章那半句是全书最有名的一次：

```
后山不……
```

写到第三个字，手抖得纸都划穿了。

**3. 三个固定动作**（相当于他的口头禅，全书反复出现）：

```
① 在地上写一个"别"字，然后用脚擦掉。      ← 他最常做的
② 摇头，摇着摇着变成点头。                ← "不行，但你还是会去，那就去吧"
③ 把自己那份吃的推过来，自己不吃。         ← 他表达关心只有这一种方式
```

**写他的时候注意**：不要给他配"心声旁白"。读者只能看见他的动作，跟云昭一样靠猜。**猜错过一次**（建议放在第 250 章前后），这样后面猜对时才有分量。

### 核心欲望

**他想把话说完。** 就这一件事，他等了几十年。

### 怕什么

**怕云昭走上跟前一个人一样的路，而他连一句"别去"都说不完整。**

### 退场

**第 950 章。用最后一口气写下真相。**

他写的不是"模拟器是什么"，是：

```
前一个持有者也是这么想的
```

**这句话的杀伤力在于：它不是答案，是判决。** 意思是——所有人都以为自己能终结它，所有人都失败了。

**出处已定（白赚的一处闭环）**：这句话不是他自己想出来的。四十一年前门口那一幕，柳寒山那几句话里有一句是"**前面那个也是这么想的**"——**老周记了四十一年，一个字没漏，最后写给了云昭**（`06-年表.md` −41 年）。

于是：**柳寒山当年拿这句话打发的那个人，四十一年后拿同一句话，把柳寒山交代给了下一个持有者。** 第 950 章不要点破出处，让读者自己接上——这一笔只对读到卷七的人生效。

写完最后一个字，他右手剩下的手指也断了。

（卷八第 951–1100 段落里，三千世中有一个没被下禁制的老周。让他把这句话说完——这是全书最后一次情感兑现。）

## 五、柳寒山（对手 / 他不是反派）

| 项 | 值 |
| --- | --- |
| 身份 | 内门执事 → 长老 |
| 年龄 | 看上去四十。**身体年龄第 1 章 341 岁**——门里那一世活了三百年，出门后四十一年（`06-年表.md`）。**这个数在卷七之前不许任何角色说破**，但所有时间推算按它来。见下面「他为什么还活着」 |
| 名字来历 | **"柳寒山"不是他本名。他本名叫云昭。** 从门里出来那天下雪，山是冷的，门口有棵柳树，他就给自己起了这个名字 |
| 一句话外貌 | **他长得不像云昭——那张脸他花了很多年才改掉。只有笑的时候，嘴角会往左边歪一下，和云昭一模一样。** |

### 视觉伏笔（重要）

"笑起来嘴角往左边歪"这个动作，**前 620 章要反复写在柳寒山身上，同时在云昭身上悄悄写三次**（建议：第 5 章第一次赢、第 180 章踩下赵堂、第 460 章金丹）。

读者在第 620 章回头想起来的时候，要起鸡皮疙瘩。**不要在揭晓时点破这个细节，让读者自己发现。**

### 说话方式

慢。喜欢用"我像你这么大的时候"这种句式——读者以为是长辈口吻，**其实全是字面意思**。这是全书最好的一处双关。

口头禅：

```
"我像你这么大的时候，也这么想。"
"别急。你还有时间。"      ← 前期像安慰，后期读者才懂：这是嫉妒，他自己没时间了
"这条路我走过。"          ← 前期像倚老卖老，字面意思是真的
```

**写他的时候注意**：他的每一句话都必须**在两个层面上同时成立**——不知情的读者读出提携，二刷的读者读出遗言。做不到双关就删掉重写。

另外埋一处：第 211–240 章某处，他说漏一件只有云昭自己知道的事（比如"昭"字是从哪本破书上抄的）。云昭当场愣了一下，随后被岔开。**这一处不要解释，等第 911 章。**

### 他为什么还活着（最终定稿：两条一起才成立，缺一条都算漏洞）

**第一条 · 门连的是世界，不是时间。** 他在门里那一世活了**三百年**，从门里出来却只有**四十一年**，两边不同步。所以他的身体年龄是 300 + 出来后的年数：第 1 章 341 岁，第 620 章 357 岁，第 950 章 379 岁（`06-年表.md` 三之 3）。

**但这一条是缺口的来源，不是答案。** 执事是筑基，筑基只能活 150 年（`03-世界观.md` 第二节）——**他从门里出来那天身体就已经三百岁，而修为几乎是空的。一副炼气的身子扛三百岁的岁数，当场就该是一具尸首。**

**第二条 · 答案：那个坏掉的模拟器还在替他续命。** 它已经不能用来模拟了，可它还没停——**它一直在从别的世界里拿年岁给他**，一点一点地喂。出门后头十八年他连筑基都不是，那十八年是纯靠这台坏机器活着的；后来补到筑基（150 年）、再补到金丹（400 年），窟窿一点点小下去，**但从来没填平过，而且它快撑不住了**。

于是三件事一次说通：

- **他为什么爬得这么慢**——一个有三百年阅历的人，筑基用了十八年（`06-年表.md` −23 年）。借来的年岁撑得住命，撑不出境界。
- **他为什么非要门后的东西**——不是贪心，是那台坏机器随时会停。**他不是想要门后的东西，他是得回去。**
- **他和魔门《换寿经》的对照**——魔门拿别人的年岁，**他拿的是别的"自己"的年岁。区别只在被拿走的那个人姓不姓云。**

**「不同步」这一条卷七之前不许任何角色说破。** 读者要是自己算出他年龄不对劲，那正是要的效果——**这是一条可以被提前发现的伏笔，不是漏洞。**

**另外**：青玄宗是围着那扇门建的这件事，**他不是查出来的，他从里面出来过。** 写他的时候不要给他安排"暗中调查宗门秘辛"的戏，那会把一个亲历者写成一个侦探，气势小一大截。

### 核心欲望

**他要终结这个循环。**

不是为了活——他早就不在乎活。**他要的是让"云昭"这个人只剩一个，别再有第三千零一个替他去死。**

### 怕什么

**怕自己已经不是云昭了。**

他做了太多事。第 33 章那张假纸条就是其中一件——他明知道会让云昭吐血，还是递了出去，因为他必须先弄清这一个云昭"够不够狠"。

他真正怕的是：为了终结它，他会变成他最讨厌的那种人。**而他已经变成了。**

## 七、写人物时的三条检查

1. **这个人有没有自己的欲望？** 只为推进主角剧情存在的人，合并掉或者删掉。
2. **他说话有没有辨识度？** 遮住名字读三句对话，认不出是谁就重写。
3. **有没有多余的名字？** 一卷里超过 8 个有名字的人，读者就开始记混。上面每卷 4–7 人是上限。
