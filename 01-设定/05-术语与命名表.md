# 术语与命名表（v2 · 2026-09-11 从零重写）

**这份表是唯一标准。** 1100 章、几个通道分头写，最大的风险不是写得不好，是前后不一致。

**用法**

1. 写正文前查一遍，不确定的词以本表为准。
2. **新造的词必须回填到这里**，不回填等于没定，下一个人会写出第二个版本。
3. 本表只管「怎么写」，不管「是什么」。是什么，查 `01-核心设定.md`、`02-模拟器机制.md`、`03-世界观.md`、`04-人物.md`。
4. 发现别的文件和本表打架，写进第九节「跨文件冲突清单」，**不要自己去改别人的文件**。

> v1（青玄宗／云昭／五境／面板系统文那一套语域）已于 2026-09-11 作者终裁整体作废，旧稿在 git `c1fdaa9`。本表不沿用 v1 任何词条。

## 一、命名法

### 1.1 人名

| 哪一层的人 | 怎么取 | 例 | 不许 |
| --- | --- | --- | --- |
| **杂役** | 姓＋数字，或单字乳名；乳名可带「阿」（阿宽），绰号可带「老」（老拐）。老杂役叫「老＋姓」 | 陈九、王二、石头、阿宽、老拐、老方 | 两字雅名、带「玄／灵／羽」这类字；节气名（那是白露一个人的取名法） |
| **外门、内门弟子** | 姓＋一到两字本名，常用字 | 三字为主 | 生僻字；同一卷里两个名字不许同声母 |
| **长老、掌门** | 道号二字，取山石草木一类实物 | 门内称「某某长老」，门外金丹以上称「某某真人」 | 本名不写；道号不取「天／玄／道／真」这类虚字，不与宗名同字 |
| **别宗的人** | 大宗弟子三字名，长老亦用道号 | — | 与玄丘宗任何人同名 |
| **凡人** | 官吏称官职（郡守、县令），百姓姓＋行当（张屠户） | — | 要紧的凡人才给全名 |
| **天命司的人** | **没有名字。** 凡人叫他们「穿麻的」，「天命司」三字卷二末前不出现 | — | 任何名字、任何编号 |

**里头的那些「他」**：一律用特征称，不用序号。「当过掌门的那个」「饿死的那个」「在沧澜学剑的那个」。序号只归面板（`【第三十七世】`），旁白与对话不数数。

### 1.2 功法名

- 二到四字，加「诀／法／剑法／术／歌」收尾。**不用「天／神／帝」开头**，这三个字留给卷五以后大宗的上乘功法。
- 玄丘宗自家功法带「石」（《青石诀》《磐石剑法》），一看就知道出自哪家。
- 杂役口传、没有字本的叫「歌」（《引气歌》），有字本的才叫「诀」。
- 一门功法一个名字，不起别名、不起简称。招式名由用到它的卷纲定，定了回填第五节（《磐石剑法》前六式已定，见 5.1；后六式归卷二纲）。

### 1.3 地名与宗门名

- 山与宗同名（玄丘山／玄丘宗）。城叫「城」、郡叫「郡」，山南为「阳」（丘阳城）。
- 大宗二字＋宗／谷／观（沧澜剑宗、丹霞谷、太衍观）。**不用「天／神／圣／仙」起头**。
- 玄丘宗内各处一律白话：老井、院心、三折道、二门。**越不起名字越像真的**。

### 4.2 修为

九境、寿元、能干什么，查 `03-世界观.md` 第一节。这里只管写法。

| 标准写法 | 禁用 | 一句话 |
| --- | --- | --- |
| **炼气一层 … 炼气九层** | 炼气期、炼气初期／中期／后期、炼气一重、练气 | **炼气只论层** |
| **筑基／金丹／元婴／化神／炼虚／合体／大乘／渡劫** | 筑基期、结丹、元神、渡劫期 | 八个词一个不改，也一个不加 |
| **初期／中期／后期／圆满** | 巅峰、大圆满、前期、末期、一重 | **只用于筑基起的八境** |
| **大境界** | 大层次、大阶 | 九境里的一级。炼气九层不算境 |
| **压基** | 筑基成功（可少量）、凝基 | 炼气九层往上那道坎，一身散气压成一颗「基」 |
| **御剑 ／ 御空** | 飞行、飞剑术、御风 | 筑基能御剑，金丹能御空。炼气两样都不能 |
| **神识** | 精神力、意念、灵觉 | 筑基起才出体。「精神力」是现代词 |

## 六、面板固定句式

以 `02-模拟器机制.md` 0.2 那张表为准，逐句登记。**面板一章不超两百字；选项每行不超十二字；死在头一天的短命世只要「始」「终」两行。** 面板不自称、不称他——没有「本座」，也没有「宿主」。

| 拍 | 固定句 | 说明 |
| --- | --- | --- |
| **入** | `【是否以此刻为始，模拟此生？】` | 只在他真睡着时出现一次。他在心里应「是」，不写他说话 |
| **入** | `【第 N 世 · 始】` | N 用汉字：`【第三世 · 始】` |
| **终（死）** | `【第 N 世 · 终 · 享年 X】` | `【第三世 · 终 · 享年十七】` |
| **终（死）** | `【死于：……】` | 死因一句话，不超十二字：`【死于：管事一脚】``【死于：沧澜剑宗一剑】` |
| **终（寿终）** | `【第 N 世 · 寿终 · 享年 X】` | **没有 `【死于】` 行。** 没死就没有回声，面板也不报死因 |
| **中断** | `【此生中断】` | 现实里被人叫醒、碰醒。**无带回**，也无 `【死于】`。这一世照旧占一个世数 |
| **带回** | `【可带回一样】` | 下接三行选项 |
| **带回** | 三行选项，每行不超十二字 | 术：`【磐石剑法 · 前六式】`；修为：`【炼气二层】`；体质：`【耐寒】`；物：`【一把凡铁剑】`。**全是他死时确实拥有、且现实里没有的** |
| **带回** | `【已带回：……】` | 选完另两样当场没了，面板不报 |
| **带回（无）** | `【可带回：无】` | 活过了头一天、死时却没有一样现实里没有的东西：这一世只有「始」「终」加这一行。**死在头一天的世不出这一行**，只有始、终两行（机制 0.2） |
| **带回（层内几成）** | `【炼气一层 · 三成】` | 修为类选项写到层内几成，成数用汉字：`【炼气一层 · 五成】``【炼气二层 · 七成】`。旁白与对话写「一层五成」「二层七成」（4.2）。几成只用于炼气 |
| **带回（指）** | 第三行偶放一样带不走的东西 | 一个名字、一处地方，形制与选项同一行；他选了也带不回。**不算带回四类，不占三选一**，每出现一次登记该卷伏笔账（机制第 4 条例外）。第一次卷一第 14 章，那新来的名字（拟 `【拴住】`，见 2.4） |
| **终（不知）** | `【死于：不知】` | 杀他的人它算不准（机制第 2 条），死因写不出，只写「不知」。卷一第 18、60 章两次，都是天命司的孟平（世界观 5.4）。**这两个字前六卷不解释。** **只给天命司**（机制第 2 条，2026-09-12 裁）：金丹以上的人杀他，面板照写名字或身份——`【死于：卧石长老】`——它认得那人，只是没算到那人会动手；「不知」是全书留给天命司的记号 |
| **抬头**（卷二末起） | `【三千世 · 第 N 世 · 始】` | 第 190 章前后第一次出现三个字，此前面板不带抬头。**具体章号与形制卷二纲定** |
| **醒**（卷三起） | 待定 | 在里头主动断掉这一世的面板句，**卷三纲定**，定之前不许写 |
| **借命 ／ 算局**（卷三、卷四） | 待定 | 卷三、卷四纲定，定之前不许写 |

**不许出现在面板里的**（机制 0.4）：模拟点、能量、经验、等级、色阶、天赋、随机、进度条、冷却、商店、每日刷新、任务、副本、奖励、结算。**面板里唯一的动词是「模拟」「带回」，唯一的名词是「世」「享年」「死于」。**

## 七、模拟相关用词

### 7.1 四层语域

| 谁在说 | 怎么叫它、怎么叫里头 |
| --- | --- |
| **设定文档、大纲** | 「模拟」「三千世」「残片」「面板」随便用 |
| **面板** `【】` | 它在说话。短句，文言味，见第六节。不用「你」 |
| **旁白** | 「他进去了」「里头」「那一世」「醒来」。「模拟」二字可写，少写；「系统」不写——世上没人这么叫它 |
| **陈九心里** | 前二十章只叫「那东西」「梦」。之后怎么改口，卷二纲定，本表一处登记 |
| **别人嘴里（不知情）** | 「这小子邪门」「他昨夜又叫不醒」。没人知道有这么个东西 |
| **别人嘴里（知情，卷五起）** | 「持有者」「他那一片」 |

**「模拟、面板、系统」三个词本身可写**（作者终裁），但它们是作者与面板的词，不是这个世界里人的词。旁白每章用「模拟」不超三处，多了就是在替面板说话。

### 7.2 核心词

| 标准写法 | 禁用 | 一句话 |
| --- | --- | --- |
| **进去 ／ 入世** | 开始模拟、进入模拟、启动 | 他睡着了，它问了，他应了 |
| **里头 ／ 现实里** | 模拟中、幻境、现世 | 配对用 |
| **这一世 ／ 那一世 ／ 头一世** | 这一局、这一轮、本次模拟 | — |
| **醒来** | 退出、返回 | 唯一说法 |
| **带回 ／ 带回一样** | 奖励、结算、获得 | 三选一。「他带回了《磐石剑法》前六式，手还跟不上」 |
| **放掉** | 舍弃、放弃选项 | 另两样没了，写「他放掉了……」 |
| **回声** | 反噬、惩罚、代价 | 疼、伤痕、虚弱三样一起到。旁白点题全书不超三次，角色嘴里叫「还」：「死一回，还一回」 |
| **伤痕挂着** | 伤痕残留、debuff 持续 | 「脖子上那道口子挂到了午时」 |

| **神魂吃不住** | 魂载不足、超载 | 「魂载」是设定文档的词，正文说人话 |
| **灰气** | 黑气、业障 | 卷三起。「他身上有一层别人没有的灰」 |
| **雾里** | 看不清、数据缺失、无法推演 | 只在设定文档说。正文写那人做了意外的事，不写「他看不清」 |
| **我见过** | 我预知、我算到了 | 陈九口头禅。「我见过你这一招」 |
| **这回换个法子** | 重来、再试一次 | 陈九口头禅 |
| **穿麻的** | 黑衣人、神秘人、天命司使者 | 凡人对天命司的叫法，卷四起 |

## 八、章名口径

**写事件，不写气氛。** 判定：读完标题能不能说出这章发生了什么。说不出就重写。出处 `.cursor/skills/fanqie-webnovel-writing/SKILL.md` 第二节。

- 十字上下，不超十五字。不带序号，不用「第 N 世」单独当章名——世数不是事件。
- 模拟内章写**他在里头干了什么、怎么死的**；现实章写**带回了什么、被谁看见了什么**。
- 判定要落在卷纲的裁决记录里：哪几章过、哪几章没过、备选是什么。口头「全部过」不算。

| 类 | 范例 |
| --- | --- |
| **模拟内章** | 头一世，他饿死在第三天 |
| **模拟内章** | 这一世他在沧澜学了六十年剑 |
| **模拟内章** | 他当了三十年管事，死在井边 |
| **现实章** | 脖子上的口子被人看见了 |
| **现实章** | 管事那一脚，他昨夜挨过一回 |
| **现实章** | 六十年的剑带回来了，手跟不上 |
| **反例（气氛）** | 梦与醒 ／ 三千浮生 ／ 夜色如墨 ／ 一切的开始 |
