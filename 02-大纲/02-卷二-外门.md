### 全书题眼（每一卷都要守住，本卷是第一次真正用上）

> **模拟里过掉的年月不算现实年龄（现实只过一息），但走过的路算数。别人拿十年试出来的弯路，他在模拟里全走完了，现实里只走对的那一条。他不是天赋高，是从来不走错路。**

**这条在本卷落到实处**：世界观说炼气九层那一层要熬三到五年，赵堂熬了二十年没过去。云昭两年从炼气三层走到筑基——**因为那三五年他在模拟里熬完了**（159 章模拟里先筑基成功过一次，177 章现实里一次就过）。**这不是开挂开得离谱，这就是这本书的题目。**赵堂就在旁边站着当参照物：同样卡在往上那一步，一个熬了二十年，一个把二十年压进了十二天。

### 晋升线（按世界观 1.2，本卷的主线骨架）

> 外门 → 内门：**炼气九层，且三年内两次外门大比进前十**；或被长老直接收徒。一年上去十个上下。

| 条件 | 什么时候拿到 |
| --- | --- |
| 第一次大比进前十 | **第 99 章**（本卷第一年的大比。第七场赢下，排第九） |
| 第二次大比进前十 | **第 127 章**（本卷第二年的大比。排第六。但他还是炼气八层，**上不去**） |
| 炼气九层 | **第 176 章**（旧伤化开当天） |
| 实际上山 | **第 181 章**，以筑基初期入内门 |

> 外门大比一年一次。本卷正好两年，两届，**他两届都进了前十**——「三年内两次」这个条件卡得刚刚好，不用凑。

**这条线是卷二憋屈感的来源，而且是可量化的**：读者能数着看他差什么。第 127 章他把两个条件里的那个"难的"先拿到了，卡他的偏偏是那个"该水到渠成的"——炼气九层。

> **两条代价要分清楚，本卷要让读者看明白**：

## 三、逐单元展开

### 单元 1｜61–72（12 章）外门的规矩 比扫地难懂

| 项 | 内容 |
| --- | --- |
| **发生什么** | 他以杂役院一年唯一那个名额进外门，住进两人一间的小院，月钱从 2 块变 10 块。外门不靠拳头，靠三样：考绩、举荐、聚灵阵的排队位次。第一天就被规矩坑了——领灵谷要一张引荐条，没人肯给他签。他模拟怎么拿到条子，模拟里三次都成，现实里三次都黄：那天管事房临时换了人，这个变量他不知道 |
| **主角靠什么赢** | 笨功夫。他把外门的规矩地图抄下来：谁管什么、哪条规矩写着但没人执行、聚灵阵一天一个时辰怎么排。抄告示、蹲**外门市集**、请人喝酒。**邓炉**（丹房杂役）在这一段接上，情报网从杂役院伸进丹房 |
| **爽点在哪** | 65 章：用一条没人执行的旧例（外门弟子有权自行申领一次考绩复核）把坑他的人拖进流程里空转半个月。70 章：靠一条冷门规矩白拿一份灵谷 |
| **结尾钩子** | 他查出来，那天临时换人不是巧合——换人的条子，是从内门递下来的 |

### 单元 2｜73–80（8 章）人一多 模拟就不准了

| 项 | 内容 |
| --- | --- |
| **发生什么** | 外门月度大课，三百多人同场。他想提前算出考评排名，连算七次，七次结果全不一样。**全书第一次系统性地撞上模拟的边界**：变量一超过他已知的部分，模拟器就拿"最合理的猜测"去填，而猜测全是错的。他差点因为算错在众人面前出丑 |
| **主角靠什么赢** | 不靠模拟。他当场收手，凭抄来的规矩地图临场改口，把一场必输的辩驳做成平局。**何长风**在这一段第一次出现——他不帮云昭，他只认云昭引的那条规矩是不是真的 |
| **爽点在哪** | 78 章：何长风当众问他"这条你从哪儿看来的"，他答"我抄的"，全场安静。**笨功夫第一次立牌坊** |
| **结尾钩子** | 他在纸上写下一行字：人越多，我越瞎。那我就别算人多的时候 |

### 单元 3｜81–92（12 章）不算整件事 只算下一步

| 项 | 内容 |
| --- | --- |
| **发生什么** | 打法转型。他把"模拟整件事"拆成"模拟下一句话、下一步、下一招"。短时高频，每次只推三五息，精度反而拉满 |
| **主角靠什么赢** | 两个理由，缺一不可，**这一段要让读者两个都看懂**：① **信息密度**——三息的窗口里，他已知的占比高，猜测的占比低；② **短模拟不耗神识**——他一天只跑得动一次长模拟，却能跑几十次三息的。**长模拟是奢侈品，短模拟是他真正的口粮。**代价只剩死亡配额，而他把那三次用到极精，只死在最关键的那一步上 |
| **爽点在哪** | 85 章（**中高潮**）：演武场，对**马冲**。马冲每一招他都提前半息知道，赢得像开了眼。马冲输完追着问他怎么做到的，他答"我算过了"，再没有第二句——**马冲成了第一个服他的同门**。88、91 各一场 |
| **结尾钩子** | 连赢第五场之后，市集上有人开始下注赌他输。下注的钱不是外门的钱 |

### 单元 4｜93–100（8 章）第一次大比 他排第九

| 项 | 内容 |
| --- | --- |
| **发生什么** | 一年一度的外门大比，在外门广场办。他一路赢到第七场，对手的路数完全在他情报之外——那人是内门临时塞进来的。**白鹤**这一届仍是第一 |
| **主角靠什么赢** | 他赢不了信息盲区，就把比试拖长，用比试本身当情报来源：打一招、记一招、再算下一招。**边打边补信息，这是他这一卷的招牌打法**，后面每一场硬仗都用它 |
| **爽点在哪** | 97–99 三章连爆。99 章（**中高潮**）他用对手自己的招收尾，**排名第九，晋升条件拿到第一个** |
| **结尾钩子** | 下场时他看见看台上一个穿内门袍子的人，冲他点了下头。那人他不认识，也没人告诉他是谁 |

### 单元 5｜101–110（10 章）赵管事来外门了

| 项 | 内容 |
| --- | --- |
| **发生什么** | **第 101 章，赵堂调任外门管事**（对表世界观 1.3）。他现在管 1200 人，手里握着发月钱、定考核、定名额、赶人下山四样权。他上任第一件事是重核云昭那一院的考绩，第二件事是把云昭**罚回杂役院干一个月**——外门最标准的处罚 |
| **主角靠什么赢** | 他谢了恩就走。**杂役院是他的地盘**：那一个月他把三年的旧关系全捋了一遍，还顺手把当年领药记档的位置摸清了（这一笔在 161–170 章要用）。他回来的时候比走的时候知道得多 |
| **爽点在哪** | 106 章（**中高潮**）：一个月满，他交上一份挑不出毛病的差事记录，赵堂签也不是不签也不是。109 章：他把在杂役院顺回来的一条消息，在市集上换了三十块灵石 |
| **结尾钩子** | 赵堂送他出管事房，笑着说：你在杂役院那三年，可不是这么干净的。**云昭愣了一下——三年前的事，赵堂记得什么** |

### 单元 6｜111–120（10 章）他没夺权 他去做那个没人愿意干的活

| 项 | 内容 |
| --- | --- |
| **发生什么** | 云昭反手拆赵堂的权。管事的权是有边界的：他能扣月钱、能派最脏的活，但**活干完了就得记**。云昭做的事是——他去接了那个全外门没人愿意干的差事：**造册。**考绩、月钱、市集换算、聚灵阵排班，全部造册报**何长风**备案。十章之内，赵堂还是管事，但每一笔都要从云昭手里过一遍 |
| **这台机关的图纸**（世界观 1.3 定的那句） | **「管事管人，执事管事。管事决定你有没有饭吃、但改不了规矩；执事决定这一场算不算数、但开除不了人。」**<br>赵堂能扣他月钱、能派他最脏的活，**唯独改不了规矩**；何长风能判这一场算不算数，**却开除不了任何人**。云昭做的事就是站在这道缝里：**他把所有事都变成"算不算数"的问题，那就归何长风管了** |
| **主角靠什么赢** | 合规，而且是最笨的那种合规。**他不害人，他只是让每一件事都留下痕迹。**<br>⚠️ **何长风一句偏袒的话都不许说，越冷越好。**他从头到尾没帮过云昭，他只是照章办事——**不是他帮云昭，是赵堂没法让规矩帮自己** |
| **爽点在哪** | 115 章：赵堂想给云昭那一院派一次额外苦役，何长风一句"报了吗"就顶回去了。119 章（**中高潮**）：**崔虎**——赵堂最贴身的那个——自己跳过来，因为跟着赵堂再也捞不到不留痕的好处 |
| **结尾钩子** | 崔虎说漏一句：赵管事这两个月往内门跑了六趟，回来就换一次考核章程。**他不知道赵堂见的是谁，云昭也不知道** |

### 单元 7｜121–132（12 章）第二次大比他排第六 谢无咎成了亲传

> ⚠️ **这一段不许写成"看着谢无咎筑基"。**按定稿，谢无咎十四岁就筑基了，那是第 1 章的**两年前**——云昭进外门的时候，人家已经筑基三年。
>
> ⚠️ **也不许暗示他年纪大。**两人**同龄、同一天上山**，本卷都是 17→19 岁。**「师兄」是身份不是年纪**：一个是谢家嫡子直接进内门，一个是弃儿进杂役院。**同岁、同日进山、五年的差距**——这样对照才够纯，任何"他比我大所以比我强"的写法都是在替云昭找台阶。

| 项 | 内容 |
| --- | --- |
| **发生什么** | 第二次外门大比，云昭排第六——**晋升内门的两个条件，"难的"那个他集齐了。**同一个月，谢无咎被一位长老收为亲传：分灵脉、藏经阁三层随便翻、议事殿有他一个位置。<br>**这不是他又快了一步，是他根本不在这条道上。**云昭还在炼气八层，为的是够到"内门弟子"这个门槛；而谢无咎已经从内门弟子里走出去了 |
| **差距的量纲要写清楚** | 原来的比法是"他比我快"，现在的比法是"**他在下一张表上**"。云昭手里那本外门的册子，记的是灵谷、排班、考绩；谢无咎那一档记的是灵脉和亲传名额。**两本册子不通用。**这一段的憋屈不是差一步，是**差一个量纲** |
| **主角靠什么赢** | 这一段他**不赢修为，赢位置**。造册这件事做了两个月，外门的实务已经离不开他。**他在自己这张表上，已经是说了算的那个** |
| **爽点在哪** | 124 章：谢无咎的师门要从外门调一批灵材，条子卡在云昭手上。他没为难，按规矩批了——但全外门都看见了这一幕，**看见的是一个炼气八层让筑基亲传等了半天**。130 章：谢无咎第一次主动来找他说话，开口还是那句"你叫什么来着"，说完自己顿了一下 |

### 单元 8｜133–140（8 章）炼气八层 他卡了一整年
