> ⚠️ **351–380 的"十年"不是单次上限。**那时他还是筑基圆满，单次一年，是**分十次接力**凑的——用的是机制文档 4b 的拼接规则，和卷三 276–288 同一条。金丹之后（456）才是一次十年。

### 拼接的误差累积（机制文档 4b）——**本卷 363–380 的地基**

| 接力段数 | 可信度 | 田大的第几年 |
| --- | --- | --- |
| 1–3 段 | 基本可信 | 第一到第三年 |
| 4–8 段 | 大方向还在，细节全乱 | 第四到第八年 |
| 9–10 段 | **基本是瞎猜** | 第九、第十年 |

> **这一条不是本段的障碍，是本段的武器。**田大死在第九年——正好落在"基本是瞎猜"那一档。所以云昭**一遍又一遍地重跑**：换起点、换喂进去的信息、换顺序。每重跑一遍，中间那几年的细节就洗一次牌；**而每一遍，田大都死在第九年。**
>
> **在一堆噪音里唯一不变的那个东西，就是真的。**这是他判定的方法，也是这一段最狠的地方——他是用模拟器的缺陷证明了那一天改不掉。

> **这一招是有价钱的，全卷不许忘**（机制文档 4c）：**重跑一遍就是一整套接力，吃神识。**他还是筑基圆满，一天只跑得动两次长模拟，所以这十段不是一口气跑完的，是他在青阳城住着、断断续续跑了**将近一个月**，前后重跑十几遍。
>
> **凡是本卷用到这一招的场面，都要先交代他哪来的时间**（351–362 他跟了两个月车、371 章他把事情推了五天）。**现场救急用不了它**——那才是它和"直接模拟一次"的分野。
>
> **这一段不许出现透支**——透支是卷三 289 章的独有代价。这里他有的是时间，缺的是办法。
>
> ⚠️ **这一段是一对里的下半，和卷三 276–290 是照着写的**（对表机制文档 4c 末尾那张对照表）：
>
> | | 卷三 276–290 | **本段（卷四 363–380）** |
> | --- | --- | --- |
> | 用的是 | 往前接（4b 拼接） | **来回磨**（4c 重跑） |
> | 有多少时间 | 二十天，四天十二次，天天超量 | **跟了两个月车，事情能推五天** |
> | 结果 | 冲错了 | **磨对了** |
>
> **没时间就只能往前冲，有时间才磨得起。**读者在卷三看过他冲错一次，本段他磨对了——**同一个人、同一个挂，差别只在手上有多少时间**。这一层不用写出来，但节奏要给足：本段的"慢"是有来历的，不是拖。

### 本卷的玩法（这一条是全卷的引擎，必须贯穿）

**十年能算完一个凡人，算不完一个修士。**

| 对象 | 十年额度够不够 | 结果 |
| --- | --- | --- |
| 一个赶车的凡人 | 够，够到看他咽气 | 他能把这个人的一生摊在桌上 |
| 一个金丹散修 | 不够，十年只是人家打个坐 | 他算不了霍山 |

所以本卷的打法是：**他打不过霍山，也算不了霍山——但他能算霍山脚下每一个凡人。所以他不动霍山，他动霍山站的那块地。**这就是金丹期的新玩法，也是"对手必须是凡人"的由来。

### 本卷唯一新增的本地势力（按裁决，只加一个，且必须是世俗的）

**青阳商会**——纯凡人的商会，管着青阳城的钱、货栈和漕船。管事是贾万金。它的对手不是别的门派，是**青玄宗自己那三条街的产业**。城里还坐着一个金丹散修霍山，从上面抽一层。

**为什么这么设**：三方全是凡人（霍山除外，而他正是云昭算不动的那个），云昭的新能力才有用武之地；同时不引入第二个修真门派。

### 本卷的一句话

**这一卷是把爽点换成重量的一卷。**他终于强到山下无敌，也第一次发现算得再准也改不了一个人能活多久。全书调性从"求生"转向"想明白点什么"，就在 373–380 这八章。

### 单元 4｜351–362（12 章）他决定算清楚一个人

| 项 | 内容 |
| --- | --- |
| **发生什么** | 他要拿田大练手。但**信息边界卡死他**：他对田大一无所知，算出来全是瞎猜。于是他做了全书最反爽文的一件事——**在青阳城住下来，天天坐田大的车，跟了两个月。**田大讲他爹、讲那匹马、讲死了的媳妇、讲儿子**小豆子**八岁了想去坊市当学徒 |

### 单元 5｜363–372（10 章）田大的十年

| 项 | 内容 |
| --- | --- |
| **发生什么** | 十次一年接力，覆盖田大往后的十年。<br>**第一年** 腰坏了，还在赶车。<br>**第二年** 小豆子十岁，想去坊市当学徒，田大不让，说赶车稳当。<br>**第四年** 田大攒够了钱，还是把名额给他买了。<br>**第五年** 车翻过一次，断了两根肋骨，养了一个月，接着赶。<br>**第七年** 小豆子出师，搬去坊市住，一个月回来一趟。<br>**第八年** 一场雨，田大从车辕上摔下来。<br>**第九年** 田大死在自己床上。小豆子赶回来的时候天已经亮了。<br>**门口那匹马拴着，草料是新添的——他死前最后做的一件事是喂马。** |

| **爽点在哪** | 不放强爽点。给两个轻的：<br>① 369 章他跑第四遍时确认第八年那一跤是能避的——只要城门口那截烂车辙填了，**十遍里有六遍不摔**；<br>② 371 章他用同一招识破一桩坊市骗局。**这一记要顺带把这招的价钱演出来**：对方催他当场拍板，他当场只用得起一次三息的短模拟，看不出问题；他推了五天，这五天里跑了四遍，**四遍里钱的去向从来没变过**——那就是真的。<br>**两百字带过，但要让读者同时记住两件事：这招很好使，而且它慢。**（对表机制文档 4c：用这一招的场面必须先交代他哪来的时间，现场救急用不了它） |
| **结尾钩子** | 他睁开眼，天黑了。田大在车边喂马，回头冲他笑了一下，问：小哥，吃了没 |

### 单元 6｜373–380（8 章）他很长时间没说话

> **全书调性最重的八章。写事，不写感慨。这八章里云昭一共说不到二十句话，其余全是他在做事。**

| 章 | 写什么 |
| --- | --- |
| 373 | 他花钱把城门口那截烂车辙填了。第八年那一跤，避掉了。他高兴了一整天 |
| 374–376 | 然后他把十年里所有能改的地方列了一张单子，一共十一处。他一处一处全做完了：车轴换新的、马换草料、小豆子的学徒名额提前两年、田大的腰找城里的大夫看了、连田大那间屋子的房梁都换了。**这三章全是做事，不许有一句抒情** |
| 377 | 做完他重新跑。**这一次他跑了三遍**，因为他已经学会了：跑一遍不算数，得看什么东西不变。<br>三遍里中间那几年全变了——腰好了、车没翻、小豆子留在城里、田大甚至多雇了个帮工 |
| 378 | **三遍的最后一年一模一样：第九年，自己的床上，草料是刚添的。**<br>十一处改动，改掉了六次摔、两场病、一回赔钱的官司。**一处都没改到那一天** |
| 379 | 他没有崩溃，也没有发火。他把那张单子折起来收进怀里，然后接着办事——这一章他谈成了三条街今年的账，谈得又快又狠。**读者要在这一章看出他不对劲，而书里没有一个人看出来** |
| 380 | 他回宗门那天，田大送到城门口，塞给他一个煮鸡蛋，还热的 |

| 项 | 内容 |

## 四、卷末高潮（453–460，逐章可写）

| 章 | 写什么 |
| --- | --- |
| 453 | 他回宗门。两件事同时压过来：一、他要算柳寒山，可算一个人的一生要十年，他只有一年；二、**宗门今年要往云台交五个弟子，名单上有他的名字**（仙盟只出现名字，不出场，对表世界观 4.1 与 4.2「每年交五个弟子」）。要在走之前把柳寒山这件事弄清楚，**他必须先结丹** |
| 454 | 结丹之前，一位长老把话说明白了：**丹要圆。心里有过不去的事，丹上就有一道裂，一辈子补不上。**云昭问：怎么知道自己有没有。长老说：结的时候就知道了。你要是有，结不成。<br>**本章只负责把规矩说清楚，说完就收。**这条规矩真正"立住"是靠后面的人——卷五互相残杀的持有者、卷六拿别人年岁活着的魔门人，一个一个用自己的裂去演。此处不许多写一个字（对表世界观 2.2 与全组年表广播） |
| 455 | 结丹的关口，他做了一件很他的事：**他没有用模拟去算怎么结丹**，因为这一次他的信息是全的。他就是坐下来，结了。**结得很干净，一道裂都没有。**<br>⚠️ **这份"干净"的原因是定稿的，不许写成"他运气好"或"他还没遇上事"**：<br>**因为他从来不让自己过不去。他算，他往前走，他不回头。这正是他的毛病。**<br>写的时候要让人隐隐不舒服，但一个字都不点破。旁边的人只会觉得这孩子心真静 |
| 456 | **金丹。**三样当场兑现：① 他端起饭吃了一口，发现自己不需要吃了；神识铺开，罩住了整座青玄山——他一睁眼就把山上有多少人在动数了一遍（**他从第 1 章起就一直在数东西**）；② 模拟上限从一年跳到**十年**，每日死亡配额从 5 涨到 8，一天能跑的长模拟从 2 次涨到 3 次；③ 他数到杂役院那条石阶上有个人在扫地，扫着扫着停下来，往主峰这边看了一眼，又低下头快步走开了——**是赵堂，躲着不敢照面**（对表人物档案回声二，一句带过） |
| 457 | **这一章前半段先把岁数那一记砸下去。**青玄宗十二位长老个个金丹，最年轻的一位一百四十岁；现在山上多了一个**二十六岁的金丹**。按修为他该进长老院，按辈分他上个月还在给内门执事递册子。议事殿为这件事吵了一下午，云昭在外面站着，一句话没说——**这一下午直接把 453 章那道调令坐实了：送他去云台，是宗门最省事的处置**（卷五入口，本卷只给到这儿）。<br>后半段回到正事：他做的第一件事，是模拟柳寒山的一生。这些年攒的关于柳寒山的所有东西全填进去——四十一年前就在、能说出门面上那层水光多久起伏一次、有一个坏掉的模拟器、说过"你比上一个快"、说过"这条路我走过"。**信息够了。够了** |
| 458 | 他闭眼。**什么都没发生。**不是失败，不是空白，不是算错——是模拟器**没有启动** |
| 459 | 他排除法：算贾万金，正常。算田大，正常。算老周，正常。算谢无咎，正常。算自己，正常。**算柳寒山，不动。**他试了整整一夜，一共十一次 |
| 460 | 第十一次的时候他忽然反应过来：**模拟器不是算不出来，是不肯算。**<br>算不出来是能力问题。不肯算，是规则问题。**这东西第一次在他面前，露出了它自己也有规矩的样子** |

**卷末必须埋进去的一笔（对表人物档案·柳寒山视觉伏笔）**：456 章金丹那一刻，云昭笑了一下，**嘴角往左边歪。**一句带过，不点破。（全书三处：第 5 章、第 180 章、第 460 章——本卷这一处落在 456）

**卷末钩子（460 章最后一句）**：他想起柳寒山临走那句"你回去自己算算我"。柳寒山早就知道会这样。也就是说——**柳寒山知道这东西的规则，比他多知道一条。**

**这一卷的大高潮为什么成立**：456 章给足"金丹 + 十年"的爽，458 章一巴掌打回来——**史上第一次，挂自己拒绝了他**。爽和悬念同章交付，新悬念的量级比旧的大一整级（从"谁在害我"升到"这东西到底是什么"），正好把读者推进卷五。
