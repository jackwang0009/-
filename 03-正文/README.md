## 一、文件命名

**一章一个文件**，四位编号 + 半角连字符 + 标题原文：

```
03-正文/卷一-杂役院/0001-管事罚我淘井 井底有块黑铁.md
```

一章一文件的理由：多通道并行时一个文件只有一个主人；单章 2200 字改一章不用加载整卷；编号即顺序，缺章一眼看得出；标题在文件名里，审校定位不用打开文件。

**分卷目录**：八个子目录，名字与章号范围以 `02-大纲/00-全书大纲.md` 第三节分卷总表为准。目录名格式 `卷一-杂役院/`、`卷二-外门/`，依此类推。

**硬规则**：编号补零到四位；标题原样抄卷纲（含中间空格），不加「第 X 章」、不加书名号；文件名里不许出现 `/ \ : * ? " < > |`；任何情况都不合并章节。

### 正文体里只准用这四种符号

**番茄不渲染 Markdown。** 正文体（元信息头以下）里任何 Markdown 语法都会原样吐给读者，所以这一层只认四样：

| 用途 | 写法 | 不许用 |
| --- | --- | --- |
| **对话** | `“……”` 全角双引号 | `「」`、`『』`、`""` |
| **面板与里头** | `【……】` 全角方头括号，给它开口（面板句）和里头（里头句，一段一个）用；现实段不许用 | `〖〗`、`[]`、`⌜⌟` |
| **句内破折号** | `——` 接在句子里 | `--`、单个 `—` |
| **省略号** | `……` | `...`、`。。。` |

**强调没有符号，场景之间没有分隔行。** 重音靠单句成段压出来；换场靠句子自己切（「第三年春。」「天亮了。」）。`【】` 有了固定含义，更不能拿去做强调——读者看见它就以为到了里头，或者是它在说话。

### 模拟内外怎么切（2026-09-25 作者裁：进入模拟后的内容都用【】）

本书六到八成正文在模拟里，**读者要随时知道自己在哪一头**。括号就是那条线，形制照参照书 `docs/模拟修仙/八年后必死？我开启模拟修仙！.txt`：

1. **入世**：`【第 N 世 · 始】` 单独成段，下一段起就是里头。
2. **里头**：每一段都是 `【……】`，一段一拍，写「你」——`【第三天早上在老井边排队打水……】`。别人的话转述为主（`【你问什么动静，他说是夜耙子耙地的动静。】`），要紧的一句留原话放在括号里（`【老方回头补了一句：“看清的都没回来。”】`）；他想事写 `【你想……】`，过稿六条的「决定必须有理由」照样管；跨时间也在括号里（`【第三年春，……】`），不另起没括号的小标。一世跨两章的续章，整章都是里头句。里头句里说起前几世，写「那一世」「上一世」「翻后山那一世」这类内容锚，不写「在里头」——人就在里头；说起现实写「外头」或「现实里」。
3. **带回**：`【可带回一样】` 与三行选项之后、`【已带回：……】` 之前，他看、想、选的那几段写「他」、不进括号——那是他在那几行字跟前，不在里头（0005、0007、0014、0018、0034 同形）。
4. **醒**：面板「终」与「带回」之后括号没了，第一段现实必带一个身体感受（疼在哪、伤在哪、天亮没亮），写「他」。**括号一断就是读者的换场信号，不另加任何标记。**

样子看 0001 末段与 0002（09-25 通道 1 试点）。

## 二、单章文件模板

复制这一整段开写：

```markdown
---
章号: 0001
卷: 一 杂役院
标题: 管事罚我淘井 井底有块黑铁
字数: 2214
对应大纲: 02-大纲/01-卷一-杂役院.md 第 1 章
本章完成的事: 交代杂役身份 / 淘井摸到黑盘片 / 它第一次问
章末钩子: 【第一世 · 始】——然后天亮了
世: 世一始
带回: 无
模拟占比: 中
爽点: 无（开卷）
伏笔: 埋-井底黑盘片 / 埋-井边不许过夜
状态: 待审校
待确认: 无
---

正文从这里开始，不写标题行。
```

**字段填法**：`对应大纲 / 本章完成的事 / 章末钩子` 抄卷纲对应那一行，钩子可以写得更好、不能没有；`世` 写本章发生的世（「世四终」「无世（未应）」）；`带回` 写他选了什么、放了什么，没有写「无」或「【可带回：无】」；`模拟占比` 填高／中／低，**并写实算**（「里头 482 字，占 22%」——里头＝从 `【第 N 世 · 始】` 到 `【终】` 之间的正文）；开卷第 1 章是全书唯一一章进模拟之前，记「低（开卷另算）」，不计入本卷例外章；`伏笔` 填 `埋-xx` 或 `收-xx`，对卷纲伏笔账；`状态` 取值 草稿 / 待审校 / 已审校 / 已定稿；`待确认` 填本章遇到的设定分歧，**不许自己拍板**；裁了之后不删原条，在其后加「（YYYY-MM-DD 通道 N 裁：……）」回填，审校才对得出账。

## 三、写一章的五步

| 步 | 做什么 | 查哪个文件 |
| --- | --- | --- |
| 1 查大纲 | 抄下「内容」「章末钩子」「世／带回」三栏，填进元信息 | 对应卷纲的逐章表 |
| 2 查设定 | 对四样：出场的人、这一世从哪一刻开始、谁在雾里、带回的那一样他死时是否真拥有 | `01-设定/04-人物.md`、`02-模拟器机制.md`、`03-世界观.md` |
| 3 写 | 短句、不解释设定；**现实段对话多于描写**；**里头段不以对话计，以「有没有一件正在他身上发生的事」计**——里头写场面，不写流水账 | `SKILL.md` 第三节 |
| 4 自检 | 过下面这张清单，不过不许提交 | 本文件 |
| 5 交审校 | 状态改「待审校」，回报派单通道 | `04-审校/README.md` |

### 文风：像人写的，不像机器排的（2026-09-19 作者要求）

参照书：`docs/模拟修仙/八年后必死？我开启模拟修仙！.txt`（网文，缺前二十章）。09-19 定的是「只学语感、不学形制」；**2026-09-25 作者裁形制也学**：它满篇的 `【你……】` 与第二人称，本书里头照着写（见第一节「模拟内外怎么切」）。它的机制不学——抽天赋、能量点、任选两项奖励、模拟到一半跳出来的选择，机制 0.4 照禁。语感上要学的仍是一件事：句子是连着的、人在想事情、话说得明白。

| 要 | 不要 |
| --- | --- |
| 句子接得上：一段里有主语、有连接（然后／可是／等到／因为），因果和时间靠词接出来 | 一段全是三四个字的碎句；每段一句、节奏一模一样 |
| 他算账时把想法写出来，一步一步，读者跟得上（可以直接写「他想」，可以用引号说给自己听） | 只给结论，靠留白和气氛让读者猜 |
| 每个决定给一句读者能懂的理由 | 靠「他看了很久」「他没说话」定格代替理由 |
| 对话像人说话，带口头语，有来有回 | 对话全是一问一答的短句，或人人一个腔 |
| 形容词少、比喻几乎不用、不堆名词 | 名词罗列（「灵田，剑，出山……」一章最多一次）、段末金句收束、排比 |

短句仍是本书底色，但**短句是重音，不是全文**；一章读下来要像一个人在讲一件事，不像一份清单。审校道四把「机器味」也算一条：连着三段以上全是碎句、或连着三段段末都是金句，报建议。

**过稿六条（2026-09-19 作者看过试点与 0023 后定，全树推 0007–0022 用的就是这六条；新写的章同样适用）**：

1. **决定必须有理由**——他每做一个决定（花钱、不花钱、跑、不跑、坐哪间棚、选哪一样带回、放掉哪两样）前后有一句读者能懂的「他想」；「他看了很久」「他站了一阵」「他知道动了是什么」若替了理由，算漏。**审校报必改。**
2. **指代必须有锚点**——用到前面章／前面世学到的事（图上哪个叉、一块灵石买的是什么、火一亮它来得快），加半句「上一回……」接上；是他自己记起来，不是旁白解释设定。**审校报必改。**
3. **碎句不成清单**——连着三段以上每段一个碎句，合成有主语有连接词的句子；日期起段要留，但三个以上日期连排各带一个碎句的，合成一句话讲完。报建议。
4. **半句指代写全**——作者脑子里通顺、读者手里断掉的短句（「图上没有了」「今天不用装」一类），改成不靳前文也读得懂的整句。**审校报必改。**
5. **口头禅限量**——同一人物的口头禅一章不超两次，第二次起换成这个人自己会说的话。报建议。
6. **钩子前给半句实的**——章末最后一句不动；若它完全靠前文才读得懂，前面补半句具体的事托住。报建议。

**手抖**（2026-09-23 通道 1 裁，09-25 补）：没写出身体缘由的手抖不拿来当情绪用；死过一回醒来那一天的虚弱可以写成手抖；写出了缘由的——竖着扫帚、扁担撑不住，冻，挨了打，一夜没睡——里头外头都行。

参照书能学的：里头的 `【你……】` 写法（09-25 起）；每个选择前把想法说出来；用到前几世学到的事顺手带一句（它反复写「上一次模拟……」，读者从不需要翻回去）。

**章首不带日子（2026-09-22 作者裁：「很多章节把日期放在第一句话，不可以这样写，像记流水账，章节之间不连贯」；2026-09-25 再裁：「为什么很多开头第一段话都要带上日期了 请你修改 去掉这个日期 而且章节又连续 有逻辑」）**：一章的第一句要接上一章的钩子——他身上的疼、他没答的那句话、他想到天灰的那件事——让读者读到第一句就知道这是同一个人的下一刻。**第一段一个日子也不许有**，哪一段都不写「这一天是 X」「今天是 X」这种报日子的句子；日子只跟着事出来（「那人是初五夜来的」「冬月初五那一夜，他没出院子」），过了一夜靠「打板」、靠上一章末的「明儿卯时」交代。里头章中按天数起段（`【第三天早上……】`）是模拟内的记法，不在此列；一世跨两章的续章（整章在里头），第一段同样只接上一章末句，里头的日子放第二段以后。**审校报必改。** 来历：0012、0014–0026 十五章原以「初五。」「十月十四。」一类独句起章，09-22 起改成钩子句、日子挪到第一段后半，0027–0030 四章 09-23 同改；09-25 作者看了说第一段还是带着日子，0004、0014、0021–0030 十二章第一段的日子删去（0004「初五还有好几天」、0030「一听听到了冬月」改写不带日子）。

**自检清单**（12 条，全过才算写完）

- [ ] 只讲了一件事，1900–2600 字；一章不跨两世（第二世死在头一天的除外）
- [ ] 标题说的是事件不是气氛（读完能说出这章发生什么）
- [ ] 章末最后一句是钩子：抛问题 / 点代价 / 推一步，三选一
- [ ] **这一世从今夜这一刻开始**，他进去时的身子、修为、手里的东西与现实此刻一致
- [ ] **里头没有它**：没有再模拟一次，没有面板以外的任何提示
- [ ] **雾**：比他高两个大境界以上的人、天命司的人，没有被写得太准；写他们做了意外的事，不写「看不清」
- [ ] **死了要还**：怎么死的写清了，醒来疼在哪、伤在哪、谁看见了；没死就没有伤
- [ ] **魂载**：这一世活了多少年，超没超本境一夜承载；超了几天不能入梦、老态写了没有
- [ ] **带回**：那一样是他死时确实拥有、且现实里没有的；放掉的两样写出来了；成色对得上他这一世活成了什么样。**面板写「无」的世，倒过来数一遍他死时身上有什么**——里头顺手拿到的院里、外门的家什（半块饼、火折子、一碗水）也算他拥有的，死前要写掉（吃了、丢了、还了），不然「无」立不住（0002、0011、0017、0021 四回栽在同一处）
- [ ] **里头每一段都在 `【】` 里、写「你」**，现实段写「他」；面板句（它开口那几句，不含里头句）不超两百字，选项每行不超十二字；第一段没有日子
- [ ] **模拟内部文字不少于一半**（例外章要在卷纲里登记）
- [ ] 没有旁白解释设定，没有生僻词、成语堆砌、现代词（术语表换法表）；英文与游戏 UI 词不写

## 四、硬指标

| 项 | 值 | 出界了怎么办 |
| --- | --- | --- |
| 单章字数 | 2200，容差 **1900–2600** | 不足 1900 = 事没讲透；超过 2600 = 塞了两件事，拆到下一章 |
| 10 章均值 | **2150–2300** | 单章可以浮动，一段不许漂 |
| 每章事件数 | 1 件 | 第二件事挪走 |
| 章末钩子 / 爽点间隔 | 必有 / ≤3 章（前 36 章 ≤2 章；**开卷第 1–4 章另算**，第一处爽点在第 5 章带回） | 没钩子就是没写完 |
| 模拟内文字 | 一章 ≥ 一半；每卷例外章 ≤ 四分之一（**开卷第 1 章不计入**） | 加一次短命世，或把现实段压短 |

## 五、多通道防撞

1. **一次只领一段连续章号，一段最多 10 章。** 领取以 MCP 派单为准，派单里的章段就是锁。
2. **只改自己那一段的文件。** 发现别人那段有问题 → 写进审校报告，不许直接动手。
3. **领段时连带读上一段的最后 2 章。** 你这段的第一章要接住上一章的钩子——**以及上一章的世数与修为**，别把他写回去。上一段还没写出来时（并行开段），按卷纲那几行接，你假定了什么全写进「待确认」，审校对缝。
4. **不许在正文里现编设定。** 大纲和设定里没有的人名、地名、数字、境界说法，一律不写；填进「待确认」，回报派单通道，由设定通道落到 `01-设定/` 之后再写。
5. **必改项没清完，下一段不许开写。**
