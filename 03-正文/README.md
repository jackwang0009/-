1100 章，多通道并行。**动笔前先看完这一页**，格式不统一后期没法救。
上游：`.cursor/skills/fanqie-webnovel-writing/SKILL.md`（写作规范）、`02-大纲/`（写什么）、`01-设定/`（不许写错什么）。

## 一、文件命名

**一章一个文件**，四位编号 + 半角连字符 + 标题原文：

```
03-正文/卷一-杂役院/0001-扫了三年地 今天他不想扫了.md
```

**为什么一章一文件**：① 多通道并行时一个文件只有一个主人，不会互相覆盖；② 单章 2200 字，改一章不用加载整卷；③ 编号即顺序，缺章一眼看得出；④ 标题在文件名里，审校定位不用打开文件。

**分卷目录**：八个子目录，名字和章号范围一律以 `02-大纲/00-全书大纲.md` 第五节分卷总表为准，这里不复制一份免得两边漂。目录名格式 `卷一-杂役院/`、`卷二-外门/`，依此类推。

**硬规则**：编号永远补零到四位；标题原样抄大纲（含中间空格），不加「第 X 章」、不加书名号；文件名里不许出现 `/ \ : * ? " < > |`；任何情况都不合并章节。

### 正文体里只准用这三种符号（2026-09-08 新立）

**番茄不渲染 Markdown。** 正文体（元信息头以下）里任何 Markdown 语法都会原样吐给读者，所以这一层只认三样：

| 用途 | 写法 | 不许用 |
| --- | --- | --- |
| **对话** | `“……”` 全角双引号 | `「」`、`『』`、`""` |
| **句内破折号** | `——` 接在句子里 | `--`、单个 `—` |
| **省略号** | `……` | `...`、`。。。` |

**两条硬规则：强调没有符号，场景之间没有分隔行。**

### 为什么场景之间不放分隔行

2026-09-08 全库删过一次：正文体里曾有 **527 行场景分隔**（先是 `---`，后统一成 `——`），已全部删除，一行不留。

- **番茄的阅读器本来就按段落留白。** 段与段之间已经有视觉间隔，再插一行符号是在一个本来就有的停顿上再加一个停顿。
- **`---` 会被渲染成一条横线，`——` 单独成行看着像残句**——两种都是版式噪音，不是叙事。
- **场景切换靠句子自己切。** 「那天夜里他开始试。」「第二天他去了点名台。」「第三回是又过了七天。」——这本书每一次场景切换的第一句都自带时间标记，**读者不需要一根线来告诉他换场了**。

### 为什么强调不给符号

2026-09-08 全库清过一次：正文体里曾有 **318 处强调标记**（先是 `**…**`，中途换过 `⌜…⌟`），已全部去掉，一个不留。三条理由：

1. **番茄成熟作者不给叙述重音加符号。** 重音靠**单句成段**压出来——这本书本来就在这么干，而且干得很好：「他数不清了。」「赢得极难看。」「可编的是脸，不是话。」**这些句子独占一段的时候本身就是重音，再套一层符号是把已经响了的话又喊一遍。**
2. **任何括号类符号都会带出「系统 UI」的观感。** `【】` 是全网系统文标配（系统提示／技能名／属性面板），`〖〗`『』⌜⌟ 同理。**而 `AGENTS.md` 红线第一条写死「不是系统文」**——用它们等于在版式上把这本书往系统文推，比正文里冒一个禁用词更难察觉。
3. **物件上的字不需要标记，因为上文都交代过了。** 碑文「擅入者死」前面是「上头四个字：」，木片「初七」前面是「背面那两个字是：」，告示「暂充」前面是「只写了一个人的班和一句话：」。**引号是多余的，去掉一个信息都不丢。**

**要强调，用这三样，不要用符号**：① 单句成段；② 把它放在段末或章末；③ 让另一个人把它说出来（0036 老四念「三场，两胜」就是全书最好的例子）。

**字数口径连带**：`字数` 字段＝正文体非空白字符数。这次清理让全树从 119,494 降到 **118,185**，**前 36 章 82,566，仍过 81,000 那道推荐评估线（余 1,566）**，六个段均值全部在线内。两次替换（`---`→`——`、去强调符号）**都是行内改动，行数净变化 0，所以既有审校报告里的段号定位全部继续有效**。往后再动符号，记得回填字数并重算段均值。

## 二、单章文件模板

复制这一整段开写：

```markdown
---
章号: 0001
卷: 一 杂役院
标题: 扫了三年地 今天他不想扫了
字数: 2214
对应大纲: 02-大纲/09-前36章逐章细纲.md 第 1 章
本章完成的事: 交代杂役身份 / 第一次模拟 / 模拟失败
章末钩子: 模拟只持续三息，什么都没看清就结束了
爽点: 无（前四章铺垫段）
伏笔: 埋-主伏笔（模拟器从哪来的）
状态: 待审校
待确认: 无
---

正文从这里开始，不写标题行。
```

**字段填法**：`对应大纲 / 本章完成的事 / 章末钩子` 抄 `02-大纲/` 对应那一行的「内容」「章末钩子」两栏，钩子可以写得更好、不能没有；`伏笔` 填 `埋-xx` 或 `收-xx`，对 `00-全书大纲.md` 第六节，没有写「无」；`状态` 取值 草稿 / 待审校 / 已审校 / 已定稿；`待确认` 填本章遇到的设定分歧，**不许自己拍板**。

## 三、写一章的五步

| 步 | 做什么 | 查哪个文件 |
| --- | --- | --- |
| 1 查大纲 | 抄下「内容」和「章末钩子」两栏，填进元信息 | 前 36 章查 `02-大纲/09-前36章逐章细纲.md`；37 章起查对应的卷级细纲 |
| 2 查设定 | 对三样：出场的人、用到的模拟、地点 | `01-设定/04-人物.md`、`01-设定/02-模拟器机制.md`、`01-设定/03-世界观.md` |
| 3 写 | 短句、对话多于描写、不解释设定 | `SKILL.md` 第三节 |
| 4 自检 | 过下面这张清单，不过不许提交 | 本文件 |
| 5 交审校 | 状态改「待审校」，回报派单通道 | `04-审校/README.md` |

**自检清单**（9 条，全过才算写完）

- [ ] 只讲了一件事，1900–2600 字
- [ ] 标题说的是事件不是气氛（读完能说出这章发生什么）
- [ ] 章末最后一句是钩子：抛问题 / 点代价 / 推一步，三选一
- [ ] 模拟时长没超当前修为上限；今天死的次数加上本章之前的，没超配额
- [ ] 模拟里的伤在现实显现了吗，有没有人看见
- [ ] 他不知道的那部分，模拟器猜错了哪一块——不能全知全能
- [ ] 这一章的玩法没和上一卷重复
- [ ] 没有旁白解释设定，没有生僻词、成语堆砌、游戏化词、现代词
- [ ] 距上一个爽点没超过 3 章（前 36 章：不超过 2 章）

## 四、硬指标

| 项 | 值 | 出界了怎么办 |
| --- | --- | --- |
| 单章字数 | 2200，容差 **1900–2600** | 不足 1900 = 事没讲透；超过 2600 = 塞了两件事，拆到下一章 |
| **10 章均值** | 前 36 章 **不低于 2250**；37 章起 **2150–2250** | 单章可以浮动，一段不许漂。36×2250 = 8.1 万字，比推荐门槛多出一点安全边距；按 2200 算只有 7.92 万，**够不着** |

> **⚠️ `0031–0040` 这一段不要拿上面那条去量（2026-08-30 补）。** 十章一段的切法是 1–10／11–20／21–30／31–40，而分档边界在第 36 章——**`0031–0040` 骑在两条线上**：`0031–0036` 属前 36 章那一档（≥2250），`0037–0040` 属 37 章起那一档（2150–2250）。**两档的合格区间不重叠，所以这一段的均值无论落在哪儿都不可解释**，按前一条量它不够、按后一条量它合格，两个结论都不作数。
>
> **这一段该看的是另外两个数**：① 前 36 章整体（**这才是关卡那道线真正要的**，2026-08-30 实测 82,455 / 均值 2,290.4，8.1 万过线，余量 1,455）；② `0041` 起满十章之后的第一段——**从 `0041–0050` 开始，十章分段与分档边界重新对齐，上面那条恢复正常使用。**
>
> 换句话说，**这是全书唯一一段量不了的**，别为它调字数。由通道 5 落 `0031–0036` 必改时报出。
| 每章事件数 | 1 件 | 第二件事挪走 |
| 章末钩子 / 爽点间隔 | 必有 / ≤3 章（前 36 章 ≤2 章） | 没钩子就是没写完 |

## 五、多通道防撞

1. **一次只领一段连续章号，一段最多 10 章。** 领取以 MCP 派单为准，派单里的章段就是锁，不另设登记文件。
2. **只改自己那一段的文件。** 发现别人那段有问题 → 写进审校报告，不许直接动手。
3. **领段时连带读上一段的最后 2 章。** 你这段的第一章要接住上一章的钩子。
4. **不许在正文里现编设定。** 大纲和设定里没有的人名、地名、数字、境界说法，一律不写；填进元信息的「待确认」，回报派单通道，由设定通道落到 `01-设定/` 之后再写。
5. **必改项没清完，下一段不许开写。**
