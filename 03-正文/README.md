## 一、文件命名

**一章一个文件**，四位编号 + 半角连字符 + 标题原文：

```
03-正文/卷一-杂役院/0001-管事罚我淘井 井底有块黑铁.md
```

一章一文件的理由：多通道并行时一个文件只有一个主人；单章 2200 字改一章不用加载整卷；编号即顺序，缺章一眼看得出；标题在文件名里，审校定位不用打开文件。

**分卷目录**：八个子目录，名字与章号范围以 `02-大纲/00-全书大纲.md` 第三节分卷总表为准。目录名格式 `卷一-杂役院/`、`卷二-外门/`，依此类推。

**硬规则**：编号补零到四位；标题原样抄卷纲（含中间空格），不加「第 X 章」、不加书名号；文件名里不许出现 `/ \ : * ? " < > |`；任何情况都不合并章节。

### 正文体里只准用这四种符号

**番茄不渲染 Markdown。** 正文体（元信息头以下）里任何 Markdown 语法都会原样吐给读者，所以这一层只认四样：

| 用途 | 写法 | 不许用 |
| --- | --- | --- |
| **对话** | `“……”` 全角双引号 | `「」`、`『』`、`""` |
| **面板** | `【……】` 全角方头括号，**只给它说话用** | `〖〗`、`[]`、`⌜⌟` |
| **句内破折号** | `——` 接在句子里 | `--`、单个 `—` |
| **省略号** | `……` | `...`、`。。。` |

**强调没有符号，场景之间没有分隔行。** 重音靠单句成段压出来；换场靠句子自己切（「第三年春。」「天亮了。」）。`【】` 有了固定含义，更不能拿去做强调——读者看见它会以为是它在说话。

### 模拟内外怎么切

本书六到八成正文在模拟里，**读者要随时知道自己在哪一头**。三条：

1. **入世**：`【第 N 世 · 始】` 单独成段，下一段就是里头。
2. **里头跨时间**用正文短句起段：「第三年春。」「他三十岁那年。」不用面板。
3. **醒**：面板「终」与「带回」之后，第一段现实必带一个身体感受（疼在哪、伤在哪、天亮没亮）。**这一段就是读者的换场信号，不另加任何标记。**

## 二、单章文件模板

复制这一整段开写：

```markdown
---
章号: 0001
卷: 一 杂役院
标题: 管事罚我淘井 井底有块黑铁
字数: 2214
对应大纲: 02-大纲/01-卷一-杂役院.md 第 1 章
本章完成的事: 交代杂役身份 / 淘井摸到黑盘片 / 它第一次问
章末钩子: 【第一世 · 始】——然后天亮了
世: 世一始
带回: 无
模拟占比: 中
爽点: 无（开卷）
伏笔: 埋-井底黑盘片 / 埋-井边不许过夜
状态: 待审校
待确认: 无
---

正文从这里开始，不写标题行。
```

**字段填法**：`对应大纲 / 本章完成的事 / 章末钩子` 抄卷纲对应那一行，钩子可以写得更好、不能没有；`世` 写本章发生的世（「世四终」「无世（未应）」）；`带回` 写他选了什么、放了什么，没有写「无」或「【可带回：无】」；`模拟占比` 填高／中／低，写完实数一遍；`伏笔` 填 `埋-xx` 或 `收-xx`，对卷纲伏笔账；`状态` 取值 草稿 / 待审校 / 已审校 / 已定稿；`待确认` 填本章遇到的设定分歧，**不许自己拍板**。

## 三、写一章的五步

| 步 | 做什么 | 查哪个文件 |
| --- | --- | --- |
| 1 查大纲 | 抄下「内容」「章末钩子」「世／带回」三栏，填进元信息 | 对应卷纲的逐章表 |
| 2 查设定 | 对四样：出场的人、这一世从哪一刻开始、谁在雾里、带回的那一样他死时是否真拥有 | `01-设定/04-人物.md`、`02-模拟器机制.md`、`03-世界观.md` |
| 3 写 | 短句、对话多于描写、不解释设定；里头写场面，不写流水账 | `SKILL.md` 第三节 |
| 4 自检 | 过下面这张清单，不过不许提交 | 本文件 |
| 5 交审校 | 状态改「待审校」，回报派单通道 | `04-审校/README.md` |

**自检清单**（12 条，全过才算写完）

- [ ] 只讲了一件事，1900–2600 字；一章不跨两世（第二世死在头一天的除外）
- [ ] 标题说的是事件不是气氛（读完能说出这章发生什么）
- [ ] 章末最后一句是钩子：抛问题 / 点代价 / 推一步，三选一
- [ ] **这一世从今夜这一刻开始**，他进去时的身子、修为、手里的东西与现实此刻一致
- [ ] **里头没有它**：没有再模拟一次，没有面板以外的任何提示
- [ ] **雾**：比他高两个大境界以上的人、天命司的人，没有被写得太准；写他们做了意外的事，不写「看不清」
- [ ] **死了要还**：怎么死的写清了，醒来疼在哪、伤在哪、谁看见了；没死就没有伤
- [ ] **魂载**：这一世活了多少年，超没超本境一夜承载；超了几天不能入梦、老态写了没有
- [ ] **带回**：那一样是他死时确实拥有、且现实里没有的；放掉的两样写出来了；成色对得上他这一世活成了什么样
- [ ] **面板不超两百字**，选项每行不超十二字，模拟内部是第三人称
- [ ] **模拟内部文字不少于一半**（例外章要在卷纲里登记）
- [ ] 没有旁白解释设定，没有生僻词、成语堆砌、现代词（术语表换法表）；英文与游戏 UI 词不写

## 四、硬指标

| 项 | 值 | 出界了怎么办 |
| --- | --- | --- |
| 单章字数 | 2200，容差 **1900–2600** | 不足 1900 = 事没讲透；超过 2600 = 塞了两件事，拆到下一章 |
| 10 章均值 | **2150–2300** | 单章可以浮动，一段不许漂 |
| 每章事件数 | 1 件 | 第二件事挪走 |
| 章末钩子 / 爽点间隔 | 必有 / ≤3 章（前 36 章 ≤2 章） | 没钩子就是没写完 |
| 模拟内文字 | 一章 ≥ 一半；每卷例外章 ≤ 四分之一 | 加一次短命世，或把现实段压短 |

## 五、多通道防撞

1. **一次只领一段连续章号，一段最多 10 章。** 领取以 MCP 派单为准，派单里的章段就是锁。
2. **只改自己那一段的文件。** 发现别人那段有问题 → 写进审校报告，不许直接动手。
3. **领段时连带读上一段的最后 2 章。** 你这段的第一章要接住上一章的钩子——**以及上一章的世数与修为**，别把他写回去。
4. **不许在正文里现编设定。** 大纲和设定里没有的人名、地名、数字、境界说法，一律不写；填进「待确认」，回报派单通道，由设定通道落到 `01-设定/` 之后再写。
5. **必改项没清完，下一段不许开写。**
