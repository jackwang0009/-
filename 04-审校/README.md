## 一、四道审校

一章要过四道，顺序不能颠倒——设定错了，写得再好也得重来。

### 道一 设定一致性（对 `01-设定/`）

机制六条各一问，再加日子、写法、钱。**每一条都要翻开机制文档对，不许凭记忆。**

- [ ] **这一世从今夜这一刻起**：他进去时的身子、修为、手里的东西，与现实此刻一致（机制第 1 条）
- [ ] **里头没有它**：没有再模拟一次，没有面板以外的任何提示；卷三前没有人在里头「醒」过来（第 1 条）
- [ ] **雾**：比他高两个大境界以上的人、天命司的人，没有被写得太准；写他们做了意外的事，不写「看不清」（第 2 条）
- [ ] **死了要还**：怎么死的写清了；醒来疼在哪、伤在哪、虚弱了没有、谁看见了；没死就没有回声（第 3 条）
- [ ] **魂载**：这一世活了多少年，超没超本境一夜承载；超了几日不能入梦、老态写了没有（第 5 条）
- [ ] **带回**：那一样是他**死时确实拥有**、且**现实里没有**的；放掉的两样写出来了；成色对得上他这一世活成了什么样；修为类没跨大境界（第 4 条）
- [ ] **世号与修为接上一章**：上一章元信息「世」栏与本章接得上；世号按 `06-年表.md` 第三节的实世号数，一夜一世，短命世也占一个
- [ ] **日子对逐日账**：今天是 D 几、什么月令，对 `06-年表.md` 第三节；里头的日子与现实同历，模拟内的「第三年春」「初五」也要对得上他进去那一夜的月令
- [ ] **人名、地名、功法名、境界写法**以 `05-术语与命名表.md` 第二、三、四、五节为准（本页不列名字，免得再过期）
- [ ] **钱**：月钱杂役一块、外门十块、内门五十块、执事一百块（世界观 3.1）；灵石量词「块」，物价对世界观 3.5

### 道二 对大纲（对 `02-大纲/`）

- [ ] 大纲「内容」栏那件事，这一章做完了吗
- [ ] 章末钩子和大纲对得上吗（可以更好，不能没有）
- [ ] 该埋的伏笔埋了、该收的收了吗（`00-全书大纲.md` **第五节**伏笔收放时间表，加该卷卷纲的伏笔账）
- [ ] 有没有提前用掉后面卷的爽点
- [ ] **出场时机**：「天命司」第 190 章前不许；「算天盘」「残片」卷四前不许；上一任的名字卷七前不许；其余见世界观第六节出场时机表
- [ ] 模拟玩法是不是本卷该有的那种（`02-模拟器机制.md` **第三节**玩法演进；借命、算局定细则之前不许出现）
- [ ] **模拟内文字占比 ≥ 一半**；不到一半的例外章，在卷纲里登记了没有（每卷例外 ≤ 四分之一；**开卷第 1 章是全书唯一一章进模拟之前，记「低（开卷另算）」，不计入**）

### 道三 叙事质量

- [ ] 只讲了一件事；一章不跨两世（第二世死在头一天的除外）
- [ ] 距上一个爽点几章（`03-正文/README.md` 硬指标：≤3 章，前 36 章 ≤2 章；**开卷第 1–4 章另算**，第一处爽点在第 5 章带回——全书大纲节奏规则 1）
- [ ] 章末最后一句属于哪种钩子：抛问题 / 点代价 / 推一步。说不出就是没钩子
- [ ] 标题读完能说出这章发生什么吗
- [ ] **现实段对话多于描写；里头段不计对话，计有没有一件正在他身上发生的事**（skill 八.1、八.3：模拟里的对话不算数）。这一条只出「建议」，不出必改
- [ ] 凄惨段有没有一点自嘲或荒诞——纯写苦，读者会累

### 道四 文字规范

- [ ] 生僻字；四字成语堆砌（一段两个以上就标）；长句套从句
- [ ] 旁白解释设定（出现「原来……是因为……」式说明就标）
- [ ] **机制 0.4 那串一个不许有**：模拟点、能量、经验、等级、色阶、天赋、随机、进度条、冷却、商店、每日刷新、任务、副本、奖励、结算——正文与面板都不许。**「模拟」「面板」「系统」三个词可写**（术语表 7.1：旁白「模拟」每章不超三处；「系统」旁白不写，世上没人这么叫它）
- [ ] 现代词：以 `05-术语与命名表.md` 7.3 换法表为准（概率、数据、效率、信息、状态、资源、概念……）；英文与游戏词一律不写
- [ ] **面板 ≤ 200 字；选项每行 ≤ 12 字；模拟内部第三人称，不写「你」**（面板里也不用「你」）
- [ ] 正文体只准四种符号：`“ ”`、`【 】`、`——`、`……`；没有 Markdown，没有分隔行，没有阿拉伯数字（`03-正文/README.md` 第一节、术语表 5.2）
- [ ] 字数出界（1900–2600）；本段 10 章均值 **2150–2300**（`03-正文/README.md` 第四节硬指标，那是唯一一份）

## 二、报告格式

**一段一个文件**，和正文章段对齐：`04-审校/0001-0010.md`。同一段复审不新建文件，在末尾追加「第 2 轮」小节。

```markdown
# 审校 0001–0010（第 1 轮）
审校：通道 N　日期：2026-09-12
结论：必改 3 处（0003、0007、0009），建议 5 处，其余通过

## 必改
| 定位 | 道 | 问题 | 依据 | 建议改法 |
| --- | --- | --- | --- | --- |
| 0007 / 第 41 段 / "面板上第三行是那柄" | 一 | 带回的那柄剑他死前三年就丢了，违反机制第 4 条 | 02-模拟器机制.md 第 4 条「必须是死时拥有的」 | 换成他死时确实握着的东西，或把丢剑那一段删掉 |

## 建议
（同样五列）
## 可忽略
- 0005 第 3 段两个成语连用，不影响阅读
## 主笔回执
| 定位 | 处理 | 说明 |
| --- | --- | --- |
| 0007 / 第 41 段 | 已改 | 改成死时手里那把柴刀 |
```

**分级**

| 级别 | 什么算 | 主笔怎么处理 |
| --- | --- | --- |
| **必改** | 违反设定、违反机制六条、没完成大纲那件事、伏笔埋收错位、章末无钩子、字数出界、出现了不该出现的词、模拟内文字不到一半而卷纲未登记、面板超两百字 | 当轮必须改完，改完回审 |
| **建议** | 能读但不够好：爽点弱、对话干、钩子平、标题偏气氛；**现实段对话少于描写**（道三那一条只到这一级） | 可以不改，但要在回执里写一句为什么 |
| **可忽略** | 个人口味 | 记录即可，不用回 |

**定位格式**：`章号 / 第 N 段 / 原句前 8–10 字`。三样缺一不可——只写章号，主笔找不到；只写句子，重复句会歧义。段号从正文第一段算起，元信息头不计，逐个非空行计段（与 `agents/workflow.md` 门禁扫描的段号口径一致）。**定位带原句是为了段号漂了也找得到**——正文是会被改的，段号活不过一轮修改，原句在改动之后仍然搜得到。

## 三、什么时候审

| 时机 | 范围 | 力度 |
| --- | --- | --- |
| **每写完 10 章** | 这 10 章 | 四道全过 |
| **第 36 章** ★关卡 | 0001–0036 全量 | 四道全过 + 通读连贯性 + 逐章数字数 + **核总字数：36 章合计 ≥ 8 万字**（平台推荐评估的字数线；36 × 2200 ≈ 7.9 万，所以前 36 章均值要压在 2200 以上，比 `03-正文/README.md` 硬指标的下界 2150 高一档。MCP-1 2026-09-12 裁） |
| 每卷末 | 全卷 | 道一 + 道二全过；道三、道四抽查三章；**数一次累计世数、对一次带回收支**（全书大纲第三、五节） |
| 主笔觉得不对 | 点名的几章 | 按需 |
| **任何已被引用的设定被改**（走了裁决记录） | 引用过这条设定的全部卷纲与正文 | 只走道一、道二；**先全库搜旧措辞，再逐处读**——**旧数字好搜，旧写法搜不到** |

第 36 章那一轮是**推荐评估关卡**，过不去后面写得再好也没人看——**不许省，不许抽查。**
**最后那一行是唯一不能用搜索代替人的一道**：旧场景里往往一个错字都没有，只是动机变了。必须有人带着新规则重读一遍。
**门禁**：一段的必改项没清完，主笔不许开下一段。

## 四、审校不得直接改正文

**硬规则：审校只写 `04-审校/` 下的文件，一个字都不动 `03-正文/`。** 三个理由：

1. **语感是一个人的。** 审校顺手改两句，主笔下一章接不上自己的调子，1100 章下来全书调性会碎。
2. **会撞车。** 多通道并行，审校和主笔可能同时开着同一个文件，直接改就是互相覆盖。
3. **审校可能是错的。** 他没有主笔手里的全部上下文。出清单，判断错了成本是回执里一句话；直接改，判断错了要回滚。

发现问题只有一个出口：写进报告，定位到句，给建议改法，让主笔决定。
