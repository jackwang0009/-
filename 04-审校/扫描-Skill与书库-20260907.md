## 二、书库：09-06 的定性结论加一层定量

09-06 `体检-总报-20260906.md` 第二节的结论——**对语句通顺、情节连贯、人味三件事，书库的指导意义是零**（因为它按设计只存元数据，不存任何一句正文）——本轮复核成立，不重复论证。

下面是那份报告没有量过的部分。数据源：`书库归档/books/*.json` 100 份，2026-08-26 快照。

### 2.1 它是一批长跑成功者，不是一批新书

| 分位 | 字数（万） |
| --- | --- |
| 最小 | 6.6 |
| 25% | 111 |
| **中位数** | **345.2** |
| 75% | 529.1 |
| 最大 | 3066 |

**中位数 345 万字。** 而 skill 的基准线样本（`.scrape/fq_books.json` 里 15–25 万字那 108 本）是新书区间，`benchmarks.md` 第 1 节量过：高分组书龄中位 53 天／114 章。

两份数据回答的是两个不同的问题：

| | 书库归档 100 本 | `.scrape/fq_books.json` |
| --- | --- | --- |
| 形状 | 中位 345 万字的长跑者 | 含 15–25 万字新书 108 本 |
| 能回答 | 一本玄幻怎么撑过几百万字 | 一本新书能不能活过前几十章 |
| 本书当前处境 | 52 章、约 11.9 万字，**还在后一个问题里** | ← 现在该用的是这份 |

本书目标 1100 章 × 2200 字 ≈ 242 万字，落在书库的 25%–中位之间。**所以书库不是没用，是用早了**——它是卷四以后才用得上的参照，现在书还在卷一。

### 2.4 玩法最近邻只有五本，且一本都不在番茄

全库按 `书名 + 核心设定 + 简介摘要 + 内容标签` 搜「模拟／苟／杂役／重来／死亡／推演／先知／轮回／预知／回档」，命中五本：

**五本全部不在番茄。** 而 `benchmarks.md` 第 7 节里那三本真正的番茄模拟流（《开局模拟被打爆》《瘟疫模拟》《一年抽取一词条》）**一本都不在这 100 本库里**。

这与 09-06 总报 2.3 节的判断同向，并把它推得更硬：书库在「本书这一路玩法在番茄卖得怎么样」这个问题上**不只是薄，是空的**。该问题的唯一数据源是 `.scrape/fq_books.json`，而 `benchmarks.md` 第 8 节已经给了答案——**模拟 × 苟 × 修仙三者同时命中 0 本。**
